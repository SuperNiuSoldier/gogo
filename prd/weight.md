## 1. 默认成长线

参照[体重稿](../design/references/tupina/booplog-weight.jpg)，一条克制的纵向细线串起日期、实际数值、照片与短备注，节点左右交替。默认最新在上，旧记录可连续向下查看；这是 Go狗明确选择的排序，不声称参考产品使用同一手势。

每个节点首先读到体重和日期，照片来自该次称重，缺照片则以文字节点收拢布局，不重复摆放同一头像。照片保留狗狗主体，不能把数据和日期旋转。用户生日已知时可以显示当时年龄；只有估计年龄则不伪造精确月龄。大字号或窄屏退为同侧排列，保持线、点、文字的归属清晰。

## 2. 趋势视图

页头「成长线 / 趋势」切换，可记住当前狗的视图偏好。趋势显示实际时间和千克单位，默认最近 3 个月，可选全部或日期范围。范围内所有有效记录均参与绘制，密集时减少标签，不丢点或按日随意取平均。

点选测量点能看到完整时间、数值、与前一笔的差值和该次照片。图下照片 / 测量条目随选中点联动；没有照片时用日期与数值，不放其他日期的图。轴根据真实数据留出余量，无数据不画线，一笔只画一个点。相同时间保留各笔，通过列表区分，不修改发生时间以制造斜率。

不标健康等级、不推算目标体重、不因一般涨跌给医疗建议。差值为当前笔减前一笔；删除或修改后重算。用可读记录列表提供图表之外的等价信息，颜色不是唯一标识。

## 3. 新增与修改

「记体重」打开短面板，默认只有空数值输入、千克单位、添加照片入口和保存。日期默认为现在，可点日期调整；备注按需展开。数值为有限正数，最多两位小数；上次体重只能作为辅助文字，不自动填入当成新测量。较大值不凭犬种知识硬判错误，输入格式错误则保留并指出。

照片选填，可从当前狗已导入相册中选取，或系统拍摄 / 选图；所选图片与测量时间不同也不修改测量时间。最多一张作为节点照片，需要保存原关联。关闭未完成表单先处理草稿，已有记录编辑沿用原 ID 和宠物。

保存成功后回成长线定位新节点，趋势与相册同步。不新建第二份“体重相册”，也不重复创建照片日记。点节点进入详情，支持编辑、删除；删除体重不默认删除照片，遵守[媒体规则](photo-album.md)。

## 4. 状态与验收

- 空记录：短提示和「记体重」，没有示例数字。
- 一笔：一个成长节点 / 一个图点，没有趋势判断。
- 多笔：按真实发生时间展示；10 笔、100 笔下不重叠关键数值。
- 无照片 / 缺照片文件：数值、日期和编辑仍可用，提供更换图片入口。
- 修正早期体重、删除中间点、跨狗切换、主题切换后，两种视图与导出必须一致。
- 成长线 / 趋势 / 新增面板需分别交付双主题设计，不能只展示数值表单截图。
