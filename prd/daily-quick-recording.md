# 脚印、日记与照护 · PRD 1.0

更新：2026-10-12。脚印是一个能持续回看的内容页；记录动作收在「记一笔」中。默认六项为用户已确认需求。

## 1. 回看先于功能目录

页头为「脚印」，提供「日记 / 全部」二选一，默认日记。日记视图借鉴参考叠卡：当前卡显示日期、正文摘要、照片，相邻真实记录露出一部分。

2026-10-12 用户进一步明确：这里使用**正面上下滑动，并在滑走后呈现毛玻璃般的模糊**。中间一张完整清晰，前后相邻卡分别露在上方和下方。上滑时当前卡向上移出并逐渐模糊，下一张从下方滑入并恢复清晰；下滑反向回看。卡片始终保持正面、原尺寸，不做立体翻转。滚轮、触控板和触屏使用同一连续位置，松手后对齐最近的一张；首尾有界，不循环制造重复日记。位移和模糊程度连续跟随手势，滑回阅读位置后恢复清晰。

底部仅保留「记一笔」，移除左右翻页箭头；键盘上下键、Page Up / Down 和首尾定位作为可访问替代，点当前卡打开全文。关闭详情返回原阅读位置，切换主题保留位置，切换宠物展示对应日记。标题、顶部宠物栏和底栏保持稳定。

停稳时最多显示三张真实日记，不在只有一条时制造背后的假记录。模糊仅作用于离开阅读位置的卡片内容，不模糊顶部、底栏或详情，不修改照片原件。纯文字卡自然铺开，无图不放假照片；长文字或放大字号时保留日期、摘要、照片与详情入口，全文在详情内完整阅读。减少动态效果时改为单张清晰卡静态切换，仍可上下滚动和键盘翻阅。

「全部」按日期倒序排列轻量记录行，覆盖照护、日记、体重、健康与里程碑；同一发生时间以创建时间、ID 稳定排序。日期和类型筛选各一层，默认不筛选；没有页内宠物筛选。可快速回到今天，旧记录按月加载，读到哪里保持位置。

常驻「记一笔」按钮打开快记面板。六项图标加文字固定顺序，已记录项显示今日次数，日记显示篇数；零记录不以“未喝水”等文案推断实际行为。最后一行是「其他记录」，不把健康、设置和陪玩混在六宫格中。

## 2. 快记的行为

| 类型 | 首次点击 | 补充内容 |
|---|---|---|
| 喂食 | 以当前时间保存一次 | 食物、克数、备注 |
| 喝水 | 以当前时间保存一次 | 毫升、备注 |
| 尿尿 | 以当前时间保存一次 | 用户选择的状态、位置、备注 |
| 便便 | 以当前时间保存一次 | 用户选择的状态、照片、备注 |
| 遛狗 | 保存一次已经完成的遛狗 | 分钟、备注；不是开始计时或 GPS |
| 日记 | 打开日记编辑，不先建空记录 | 正文或照片至少一个，首版每条最多 9 张 |

五项快记只必有宠物、类型和发生时间。没有数量时不能汇总为饮水量、食量或时长；不默认排便正常。保存成功给出宠物、类型、时间，以及补充 / 撤销；面板保持展开，便于接着记另一项。

同一保存请求仅写入一次，重试沿用操作 ID；按钮在该次写入中给反馈，不能靠固定延迟屏蔽后续真实记录。多次真实事件不自动合并。错误保留现场，写入成功后才更新次数。

## 3. 日记与其他记录表单

日记默认当前时间、无标题必填、正文区域与添加照片入口；选图不要求再次选宠物，取消选图保留文字。正文最多 10,000 字，最多 9 张为本轮容量提案，超限在选择前说明；工程需评估，不延续 Web 的 5 MB 临时限制。查看日记可浏览所有照片，卡片只用第一张和数量标记。

「其他记录」只提供下表的记录种类，一次选择即填必要内容。时间、备注、照片和安排下次提醒按需展开；有旧值的字段在编辑时可见。体重走独立体重页，不复制入口。

| 类型 | 必填 | 选填或规则 |
|---|---|---|
| 洗护 | 洗澡 / 美容二选一，默认洗澡 | 备注、照片 |
| 训练 | 类型本身即可记录一次 | 项目、时长、备注 |
| 疫苗 | 实际疫苗名称 | 批次、机构、凭证照片、下次日期 |
| 驱虫 | 实际药品或项目 | 内 / 外驱、实际用量与单位、凭证 |
| 用药 | 药名、实际用量文本、单位 | 用法、备注；单位支持自填，不计算推荐剂量 |
| 就诊 | 主诉或就诊原因 | 机构、处理记录、报告照片；不自动诊断 |
| 第一次 | 事件标题 | 正文、照片；回看进入日记和全部 |
| 自定义 | 事件名称 | 数值与单位、正文、照片 |

便便和健康凭证照片默认不进首页相册；可主动设为可展示，详见[相册](photo-album.md)。健康附件首版支持照片，不把医疗判断或 PDF 文档识别列为已具备能力。

## 4. 时间、编辑与删除

- 发生时间和创建时间分开，允许补记过去，不接受未来已发生记录。下一次计划保存到提醒。
- 日统计按当前设备时区的日历日边界计算；记录保留原发生时区，详情显示原时间。跨时区时当前日分组可能改变，不能修改原时间戳；跨午夜恢复前台重新统计。
- 详情提供编辑、删除和原照片查看。修改沿用 ID，不增加一条新记录。编辑新增的提醒安排要显式确认，不静默更改既有提醒。
- 撤销作用于最近一次具体写入：新建撤销移除本次记录，修改撤销恢复上个版本。跨狗后仍作用于原 ID，反馈写明归属；版本已变则不覆盖更新。
- 删除记录前明确说明照片保留方式；默认照片留在相册，健康隐私照片仍隐藏。媒体彻底删除另有确认。删除或撤销称重，同步移除趋势点；删除提醒完成记录不自动重新打开待办。
- 日记和照片的持久化为一个可恢复事务，断电或存储失败不能留下“已保存但无照片”的假成功。

## 5. 必须验证的场景

六项入口稳定、每天多次记录、重试不重复、昨天补记不算今天、编辑后所有视图一致、无照片日记、九图与长文、跨宠物撤销、不同主题保持原归属、失败不丢草稿。完整验收编号见[验收清单](acceptance.md)。
