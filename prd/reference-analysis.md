# 参考稿逐页拆解

日期：2026-10-12。主要依据为用户提供、已逐张查看的四张 BoopLog 设计展示截图，画面标注「小鱼郭（设计师版）」。它们是静态展示稿：可观察构图，截图标题声称的功能与未展示的手势、动画、持久化、性能需分开看。没有安装该产品，本轮不重新核实商店状态。原图与来源见[参考目录](../design/references/tupina/README.md)。

## 1. 日记与相册

来源：[日记 / 相册图](../design/references/tupina/booplog-diary-album.jpg)。

**可见**：日记页有多张大小与前后层级不同的纸卡，前景是一条可读的日期、文字和右侧照片，背后还有其他日期记录；相册页由多张不同角度的照片形成密集而有节奏的主体。两页共享一条五位置底栏，中央圆形控件更突出。页面内标题只是「日记」「相册」，没有大段欢迎语或功能解释。截图标题写着照片自动收集到相册。

**设计推断**：重点是积累内容后的回看感，单条内容在阅读时成为焦点；照片与日记属于同一个资料集合的不同视图。仅凭图不能确认卡片具体怎么拖动、照片是否自动抠图、底栏每个按钮的实际行为。

**Go狗采用**：脚印中「日记」视图使用可翻阅的真实记录叠卡；相册是默认首页，有散落照片、点击放大和手动 / 自动流转。日记和体重中允许展示的照片自动汇入相册，同一张媒体不重复存储。不再要求分别上传“首页照片”和“日记照片”。常规照护流水仍单独可看，满足用户高频记录。

## 2. 体重的两种回看

来源：[体重图](../design/references/tupina/booplog-weight.jpg)。

**可见**：左页是纵向细线串起照片、日期、月龄、体重和短备注，节点左右交替；右页是细折线和对应的小狗照片、数值、日期。两种表现共享「记体重」按钮，页面标题附近有视图控制。

**设计推断**：照片把抽象的数值变成成长经历，用户既能看当时的模样，也能看变化。照片的加工方式、图表筛选、缺照片和未知生日的表现没有展示。

**Go狗采用**：独立体重页默认照片成长线，可切换趋势；新增数值在短面板完成。照片必须来自该次测量附件，无照片就使用文字节点，不拿当前头像假装当时的照片。月龄只在生日已知时显示，默认不自动估算。撤掉“表单占主屏，图表附在保存按钮下面”的旧结构。

## 3. 提醒的日历与动作

来源：[提醒图](../design/references/tupina/booplog-reminders.jpg)。

**可见**：上方是一周日期、今天高亮、回到今天和展开控制；下方是轻线事项与完成标记。新建在底部面板内，包含类型网格、备注、宠物选择和日期时间。

**设计推断**：浏览当天安排是主任务，写提醒是暂时动作。截图不能证明完成是否生成记录、如何重复、通知是否送达。

**Go狗采用**：保留周历 / 月历与短面板；明确逾期、完成、跳过、延期。按用户已确认的全局切狗规则，去掉面板里的再次选宠物。事项、时间先填，类型和重复按需展开，避免九宫格变成第一步必选考试。

## 4. 导出是一份可读的记录

来源：[导出图](../design/references/tupina/booplog-export.jpg)。

**可见**：页头菜单含设置、切宠、分享与导出；导出展示中有标题、时间范围、宠物档案、照片、体重曲线和底部输出操作。截图标题声称全部记录可导出 PDF。

**Go狗采用**：当前狗的日期范围 → 内容预览 → 系统保存 / 分享。输出应包含真实照片和可读分页，不把导出按钮当功能完成。保留顶部唯一切宠，菜单不再重复宠物列表。PDF 是阅读文档，可恢复备份另设明确入口。

## 5. 旧方案与参考的实质差距

| v0.12 的问题 | 对产品的影响 | 重构要求 |
|---|---|---|
| 固定插画封面与工具面板主导 | 看不到自己积累的生活内容 | 相册默认页，真实照片持续增长 |
| 一张卡片加装饰纸边 | 只有局部风格，无法评估长期回看 | 明确多条日记焦点、顺序、翻阅和无图状态 |
| 12 项等权目录承担所有低频功能 | 体重、提醒难发现，页内目标不清楚 | 四个内容页各自有首要任务；新增照护才展开类别 |
| 首页相册与记录附件独立 | 需要重复操作，删除关系不清楚 | 统一媒体及来源关联 |
| 体重藏在编辑表单下面 | 数据累积后仍像录入演示 | 先看成长线 / 趋势，再按需新增 |
| 仅内存保存，导出未打通 | 无法每天持续使用 | 持久化、失败恢复、PDF 与备份列入首版验收 |

## 6. 贴近的程度与明确差异

贴近参考的页面骨架、内容比例、细线、照片疏密、克制主按钮与统一底栏。保留 Go狗的圆润中文、奶白 / 黑棕两套配色、顶部头像与高频照护；这些是用户自己的要求。照片墙的错位限于视觉，不遮挡文字或缩小点击区；不复制社交平台外围、大字推广语、他人的宠物、作者标识或测量数据。
