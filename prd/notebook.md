# 相册与脚印：最新导航约定

2026-10-13：相册支持照片和视频混合导入。视频以封面和时长进入原有卡片，点击播放，归属发起导入时所选狗狗；详细规则见[视频导入](video-import.md)。

最新命名调整：原「脚印」改为「相册」，原「记事」改为「脚印」，仅修改名称，不改变页面职责、记录数据或交互。

最新拍照调整：相册的「记一笔」直接启动拍照，成功后保存一张照片及一条关联照片日记，无文字必填；取消不产生记录。移除底栏独立拍照入口，当前底栏仅为相册 / 脚印 / 提醒。脚印页保留各类小事的快记和成长串线。浏览器使用带相机提示的文件选择器，手机真实相机行为待真机验证。

2026-10-12 用户明确调整，优先于此前五入口和独立相册 / 体重页的方案。

- 此前独立照片墙已移除，默认进入现名「相册」的原脚印页；底栏为相册、脚印、提醒，拍照在相册「记一笔」中完成。
- 相册保留日记卡片、上下滑动、划走模糊、全部记录和原有新增 / 编辑 / 删除逻辑。选图、照片查看和播放收进相册；选入照片形成照片相册，不要求再次上传。
- 体重页改为脚印，默认以照片成长串线展示所有小事：称重、喂食、喝水、尿尿、便便、遛狗、日记与自写小事。节点是已有记录的另一种视图，不复制保存一份。
- 时间线按发生时间倒序排列，节点关联日期、真实附件、类型、数值或文字；无照片使用类型图标，不拿头像冒充当时照片。点击节点进入原记录详情。
- 「记一件小事」打开快速面板，支持日常项目、体重和自由文字；快捷记录后留在脚印页。称重仍保存 kg 数值，其他小事不强求数值。
- 顶部统一切狗、独立双主题和提醒不变。此轮布局仍为浏览器原型，持久化和真机验收未完成。
