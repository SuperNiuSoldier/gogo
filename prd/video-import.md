# 相册视频导入

更新：2026-10-13。用户要求相册支持视频导入，沿用[相册 / 脚印 / 提醒](notebook.md)三入口，不增加视频专区。

## 使用方式

- 相册右上角的导入入口和菜单统一为「导入照片或视频」，打开系统选择器，可混选。只处理用户选择的文件。
- 导入发起时锁定顶部所选狗狗；异步处理期间切换狗狗不改变本批归属。取消选择不产生记录。
- 每个成功导入的项目形成一条关联日记，照片和视频在现有卡片中一起浏览。视频显示封面、播放标记与时长，不新增说明卡片或分类栏。
- 点击视频记录进入详情，提供播放 / 暂停、进度与音量控制；默认暂停，不在列表自动播放。关闭详情、切换预览内容或退到后台时停止播放，返回后由用户主动播放。
- 相册的照片流转遇到视频时停下，不自动跳过正在观看的视频，也不自动播放声音。
- 视频记录可补写文字、编辑和删除，脚印成长串线引用同一条记录及其封面，不复制记录。日记附件支持复用已有视频。
- 「记一笔」仍直接拍照；本轮不增加录像操作。体重附件保留照片。

## 异常与数据

部分文件无法读取时保留成功项，提示成功数量与失败原因；失败文件不创建空记录。未支持的编码明确告知失败，不将视频静默降级为一张图片。

正式版媒体模型需记录类型、原文件、封面、时长与尺寸；原件与记录关系持久保存，重启后仍能播放。封面可重建，不能以封面替代视频原件。PDF 只展示封面和时长，数据备份则需包含视频原件。相关要求见[数据与恢复](data-and-export.md)。

## 当前原型边界

- 主原型和字体对照稿共用实现。浏览器本地读取视频原件，生成封面，不上传服务器，不做转码或剪辑。
- 每批最多 20 项；单段视频 200 MB、单张照片 20 MB 是本次原型的处理限制，正式版容量需真机验证后确定。
- 数据保留在当前预览内存中；切换设计方案保留，刷新 / 重新打开后丢失。导入日期使用当前日期，尚未读取拍摄时间。
- 已验证的格式和场景见[本轮实施](../doc/steps/01-video-import.md)。选择器允许视频不等于所有容器和编码均已兼容，iPhone MOV / HEVC、云端相册下载和真实手机相机尚未验收。
