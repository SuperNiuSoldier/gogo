# 相册与拍照 · PRD 1.0

当前约定：底栏为相册 / 脚印 / 提醒，相册保留日记卡片与上下滑动，「记一笔」直接拍照；导入入口支持照片和视频。以[最新导航](notebook.md)和[视频导入](video-import.md)为准。下文旧页面说明保留为调整前记录。


更新：2026-10-12。相册为默认首页，主要面积展示当前狗狗的照片，取代固定演示插画封面。参考依据见[日记 / 相册拆解](reference-analysis.md)。

## 1. 一眼看到照片

顶部只有页名、共享头像栏和低频菜单；主体为照片散落布局，底部保留五入口。正常字号、390pt 宽屏目标：顶部与底栏之外，照片区占可用内容高度至少 70%，3 张以上时首屏可辨认 3–7 张，1–2 张则自然放大。不按总屏幕高度硬塞图，大字号时优先保留阅读和操作。

不同大小与轻微角度形成密度，主照片清楚，较小照片构成周围节奏。位置根据照片 ID 稳定，新增后只局部更新，不在每次刷新随机洗牌。照片可略有重叠，但主脸、点击主体、日期不被遮住；点击不准时改为错位排列。无权限访问真实图时不拿肉球 / 格林插画填成用户内容。

首版以原始照片的轻微错位布局达成风格。自动主体抠图属于增强，不作为必须成功的前提；只有通过清晰度和耳朵 / 毛发完整性检查的衍生图才能展示。用户可回原图，原文件始终保留。不对原图自动去色、融合两只狗或套主题滤镜。

## 2. 来源统一，保存一次

| 来源 | 是否进入相册 | 是否生成脚印记录 |
|---|---|---|
| 中央拍照 | 默认进入 | 一条照片日记，之后可补文字 |
| 日记 / 第一次的照片 | 默认进入 | 原记录，不再生成第二条 |
| 称重照片 | 默认进入 | 原称重记录，点图可回到测量 |
| 系统照片选择器导入 | 默认进入 | 不自动生成日记；之后可写一句并关联 |
| 便便 / 疫苗 / 驱虫 / 用药 / 就诊附件 | 默认隐藏 | 原记录；可主动加入相册 |

相册条目指向统一媒体 ID，可指向一个或多个来源记录。已有媒体被再次附到记录时直接引用；同一狗重复导入相同内容复用，不把它当两个瞬间，不跨宠物自动关联。同一张有多只狗的合照由用户选定当前归属，首版不自动识别分配。

页头「添加照片」打开系统选择器，仅处理用户选中的项目，不扫描整个手机图库。首版每批最多 30 张为本轮提案，显示逐项结果，部分失败可只重试失败项；不限制库总量为旧原型的 12 张。导入后的本地副本不依赖手机图库继续授权，导入成功前不承诺已可离线浏览。

有拍摄时间且不晚于现在时作为照片时间；缺失或明显未来时间使用导入时间并可修改，不凭文件名猜日期。宠物生日、年龄不从照片日期推断。相册默认按照片时间倒序、ID 稳定排序，可按月定位。

## 3. 拍照只留瞬间

点击中央按钮时锁定宠物 ID、来源页及操作 ID，直接请求系统拍摄。首次到此才请求相机权限；拒绝时提供设置指引和从相册选择，取消不生成记录。

用户确认有效照片后，写入照片与一条照片日记；默认发生时间为拍摄时间，无法取得时用确认时间。成功后回到来源页，轻量反馈可查看、补文字或撤销。不要求填写标题、类别或再次选宠物。

写入失败保留待保存照片和重试 / 放弃；重试不复制记录。后台恢复保留该次任务，异步结果始终归属发起宠物；已取消操作的结果丢弃，不能写到后来切换的狗。相机模态期间无需提供第二个宠物选择器。

## 4. 大图与流转

点照片进入单张浏览，显示日期与来源，左右切换，提供查看原记录、加入日记、移出展示、删除等低频菜单。多条来源时先显示来源清单，不猜最相关记录。

- 照片墙提供清楚的「播放」控制，主动开启后在单图浏览中流转，默认不自动播放整个页面。
- 播放默认每 5 秒切下一张，柔和过渡约 250–400ms，间隔为设计参数，真机验证后调整；不旋转或挪动整张照片冒充小狗自身动作。
- 手动翻图、打开编辑、切狗、切标签、后台均暂停；回到前台不突然继续，需主动播放。切狗保留各自位置，但不混播旧照片。
- 减少动态效果时不自动播放、不使用转场，手动上一张 / 下一张仍可用；辅助阅读不播报自动切换，只播报手动选择。

这比旧原型默认轮播更克制，同时保留用户要求的动态展示能力。相册模式和播放是内容行为，不是独立主题。

## 5. 删除与异常

- 「移出相册展示」只隐藏媒体，原记录及文件保留，可在相册菜单「已隐藏」恢复。
- 「删除照片」明确列出关联记录数量；确认后移除所有附件引用及本地文件，不修改系统图库。若会令照片日记变空，预告将一并删除这些空记录；有文字、体重或其他内容的记录保留。
- 删除源记录默认保留照片及原时间，失去来源时作为独立照片；不自动删除其他记录共享的附件。
- 未下载完成、格式不支持、解码失败、空间不足各有明确提示；已有照片继续可用。备份包含原图和关联，衍生缩略图可重建。
- 无图显示「添加照片」和底栏拍照；一张不显示播放；多图不使用假缩略图填空位。

HEIC / JPEG / PNG 为首版需要评估并验收的常见输入；动态照片首版按静态封面保存并在导入前说明。格式、单文件处理预算和设备能力在工程基础阶段实测确定，未验证时不得宣称完整支持。
