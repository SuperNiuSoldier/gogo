# 肉球主题

日期：2026-10-13。当前状态：已依据用户新提供的照片质感参考图，用内置 imagegen 制作 12 枚角色 / 表情素材和 1 张固定背景，并接入小程序。用户视觉验收与微信真机确认待进行。原线稿方案已被用户否定，由本版替代。

## 目的与边界

肉球是用户曾经养过、已经离世的萨摩耶。主题用于怀念它，把熟悉的外形和日常动作融入小册子。保持温暖的日常感，不加入祭奠页面、虚构纪念日期或代替肉球说话的文案。

用户明确：**不要新增选择肉球照片、换背景等功能；图标也要使用 imagegen，贴近新参考图的真实毛发与照片质感。** 图标及背景作为固定资产内置，相册原有照片 / 视频导入与拍照功能保持原用途。

## 视觉

- 肉球形象：蓬松奶白毛、立耳、圆润深色眼睛、贴近镜头的大鼻子及鼻梁棕粉色斑、绿黄拼色围巾和圆形吊牌。以本轮用户参考图为准，不混入格林的黑棕花色。
- 图标：**照片质感透明抠图，不再使用描边简笔画。** 喂食是肉球伏到食碗前，喝水是舔水，遛狗是迈步，尿尿是抬腿，便便是蹲下；日记、体重、小事分别配打开的本子、秤与铅笔。保持类别文字，不能仅凭表情区分动作。
- Logo：轻轻歪头的近景；夜间使用闭眼休息姿态。相册、脚印、提醒三入口对应搭着影集、走路、按小铃铛的肉球。
- 背景：以用户提供的形象 / 风格参考图为依据，使用 imagegen 生成固定的近景写真背景。保存参考关系、逐资产提示词和输出来源；不宣称生成动作或场景是实际发生的回忆。原始参考不进入发布包。
- 布局：有记录时照片卡片仍是主体，背景在边缘提供视觉氛围；空相册可以展示主题主视觉，但不将它计作用户记录。表单面板保持实色，避免照片影响阅读。
- 文案：保留产品原有简短标签，不平铺功能说明、不额外放大段纪念文字。

## 交互与数据

顶部原主题按钮改为主题入口，打开「肉球 / 原色」选择与「奶白 / 黑棕」明暗切换。顶部切狗仍是唯一宠物切换入口。

主题与明暗分别保存：`preferences.skin` 为 `rouqiu` / `classic`，既有 `preferences.theme` 继续为 `light` / `dark`。本轮默认肉球主题；旧 v1 数据没有 skin 字段时使用肉球外观，保留原明暗偏好和全部记录。主题不会给宠物换头像，也不会改记录归属。

## 验收

1. 喂食、喝水、尿尿、便便等入口使用可区分的肉球动作图标；同类图标同步到脚印记录。
2. 肉球 / 原色与奶白 / 黑棕可组合切换，重开保留设置，切狗后记录仍隔离。
3. 图标与背景由内置 imagegen 根据用户参考生成并内置，没有背景选择、背景上传或背景移除入口；两种明暗共用自然白毛素材，不做颜色反转。
4. 小屏、大字号、夜间模式均可读可点；相册翻阅、拍照、媒体导入和串线记事继续工作。
5. 必须在目标微信开发者工具与真机验收；浏览器渲染和本地旧编译器不能替代真机。
