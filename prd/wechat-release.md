# 微信小程序首发基线

2026-10-13 用户确认开始实现小程序，先搭建工程，随后提供 AppID 并完成配置；微信编译与手机预览待验证。本文件覆盖旧 PRD 的 iOS 首发假设与过时导航；视觉与交互继续以已确认原型为准。

- 三入口：相册 / 脚印 / 提醒。相册的「记一笔」直接拍照，导入支持照片和视频；脚印用成长串线回看全部小事。宠物只在顶部统一切换。
- 新用户从空库建档。名字必填，头像、生日、到家日、特点选填；编辑保留 ID，删除须明确关联内容并确认。
- 本阶段是有本地持久化的开发版：记录元数据持久保存，媒体复制到小程序用户文件目录，成功落盘后才保存记录。草稿与正式内容分开。
- 正式首发拟采用云端保存＋本地缓存；本地开发版不承诺跨设备、清除微信数据后恢复或长期海量视频保存。云环境、费用、隐私声明与身份隔离需在后续账号接入阶段落实。
- 当前提醒只做小程序内待办；外部通知须接微信订阅授权与服务端发送，受模板、类目和授权限制。未接通时不出现“已通知”或持续每日推送的承诺。
- 字体、图标、颜色复用已确认的随手写方向；页面代码适配小程序组件，毛玻璃滑动、字体加载、视频和键盘需微信真机验收。
- 首个验收闭环：建宠物 → 拍照或导入媒体 → 查看 / 编辑 → 重开后仍可回看 → 删除确认。

后续上线仍需：账号主体与发布资格核验、云存储与用户隔离、导出与恢复、订阅消息联调、真机性能与权限验证、微信后台要求的注册 / 备案 / 隐私与审核流程。旧 iOS 计划保留为后续平台记录，不作为当前工程前置条件。
