# Go狗四页交互原型

2026-10-12，依据 PRD 1.0 重做的视觉评审版本。可读源码在本目录，当前聊天预览产物为 `../../previews/gogo-life.html`。历史 `two-dog-themes.html` 保留原样。

## 文件与构建

- `view.html`：顶部宠物上下文、内容区、五入口与模态容器。
- `style.css`：产品自身的双主题、字体、照片构图与组件尺度。
- `app.js`：四页状态、合成内容、内存交互、文件选择与宿主偏好。
- 构建：在项目根运行 `.tools/ui-preview/bin/python3 scripts/build_life_preview.py`。需项目 `.tools` 中的 fontTools、Brotli 与已下载的 ChillRound 字体源；字体许可见 `../../assets/fonts/ChillRound-LICENSE.txt`。
- 浏览器检查：先用 visualize 的 `scripts/render.py` 将片段包装为项目内 `.tools/gogo-life-check.html`，再执行 `.tools/ui-preview/bin/python3 scripts/check_life_preview.py`。

界面内只有短操作标签和内容；素材、模拟数据及尚未实施的能力在预览外说明。所有生成素材与字体随片段内嵌，无照片远程请求。Lucide 由聊天预览环境提供。

## 可评审内容

四内容页、中央拍照动作、顶部唯一切狗、独立双主题；相册散落照片与播放、日记叠卡与全部记录、照片体重线与趋势、周月历提醒。短面板支持日记、体重、提醒新增与编辑；五项快记、记录撤销、选图与照片复用可以操作。相册菜单提供回忆册排版预览，尚不生成 PDF 文件。

日记以原生纵向滚动驱动正面上下滑动：当前卡清晰，离开阅读位置后渐变为毛玻璃般的模糊，滑回后恢复清晰；卡片不倾斜、不缩放。支持滚轮 / 触控板 / 触屏，停下后对齐卡片。底部只有「记一笔」，键盘上下键与 Home / End 也可翻阅；关闭详情、切换主题保留当前篇。减少动态效果时保留单张清晰卡，静态切换。实施与验证见 [滑动与毛玻璃留痕](../../../doc/steps/01-diary-frost-scroll.md)。

宿主设计控件支持多条 / 一条 / 空内容及 125% 文字。改变内容状态会重置模拟资料；文字调整不重置记录。模拟记录与选入的图片仅在页面内存中，重新打开会丢失；只向宿主保存所选狗、主题和页面偏好。

## 范围边界

这是产品原型评审，不是可安装的 iOS App。文件选择器带拍照提示属性，能否直接调用相机由浏览器决定；未验证手机相册权限、实拍、HEIC、动态照片。提醒不会发送系统通知；无本地数据库、PDF 文件导出、备份恢复、档案管理和角色陪玩动作。

样例照片由 AI 生成，[来源及提示词](../../assets/album-samples/README.md)可查；日记、日期、体重、事项均为合成例子，默认数据不用于生产初始化。不同来源的图片暂不做内容去重；详情为方形预览；编辑时新导入的图片立即进入当前宠物相册，尚不具备原生草稿事务规则。一次最多读取 20 张、每张最多 20MB，预览压缩到最长边 1600px。

原生验收与未完事项仍以 [PRD](../../../prd/acceptance.md) 为准，不能用浏览器通过报告替代。
