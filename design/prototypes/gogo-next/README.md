| 方向 | 主要构图 | 适合的体验 | 取舍 |
|---|---|---|---|
| 影集 | 单张大照片、横向滑动、底部缩略片、轻薄导航 | 沉浸回看照片与照片日记 | 同屏照片数量较少 |

## 原型工具

采用 [.agents/skills/prototype](../../../.agents/skills/prototype/SKILL.md) 与 [PICKER.md](../../../.agents/skills/prototype/PICKER.md) 的比较方式。选择器位于上方，避免遮住底部导航；样式逐字沿用技能，方案切换即时完成。按 `1 / 2 / 3`、左右方向键切换，`R` 重建当前方案；输入框内不响应这些快捷键。

独立浏览器按 `?v=2` 保留选择。聊天 srcdoc 沙箱不允许修改浏览器历史，改用宿主偏好保存所选方向；不保存照片或个人记录。旧 `gogo-life` 保留为上轮证据，尚未替用户选择最终方向。

## 源码与构建

- `variants/`：影集、手账、日常的不同页面构图。
- `app.js`：共享数据和记录编辑能力、导航、原生滚动与照片选择；沿用上一轮已验证的记录逻辑，重构页面渲染及生命周期管理。
- `style.css`：新页面层次、尺度、双主题、材料、日记和各方向差异。
- `forms.css`：共享编辑 / 详情基础，最终呈现由新样式覆盖。
- `harness.js`、`picker.css`、`view.html`：按技能约定比较和重建方案。
- 构建：项目根执行 `.tools/ui-preview/bin/python3 scripts/build_next_preview.py`。
- 浏览器验证：包装到 `.tools/gogo-next-check.html` 后执行 `.tools/ui-preview/bin/python3 scripts/check_next_preview.py`。

旧 `check_next_preview.py` 保留四页 / 五入口时期的断言，不能作为当前三入口验证。当前媒体检查使用 `scripts/check_video_import.py`；它覆盖主原型和字体对照稿，并自动生成合成视频测试素材。

技能原文保持不变，生成的 picker 样式与上游规格一致。照片沿用已有独立双狗生成样例；字体沿用获许可的圆体并生成独立子集。[构建报告](../../previews/gogo-next/build.json)记录文件大小、字体字形和来源。

## 实际范围

这是可交互的浏览器原型。保存仅在当前页面内存中；切换设计方案可保留，重新打开会丢失。文件选择器能否直接启动手机相机取决于浏览器，系统相册权限、实拍、HEIC、通知、VoiceOver、Dynamic Type 和真机性能尚未验证。无原生本地数据库、真实 PDF 文件和备份恢复。

实施及检查见 [重构留痕](../../../doc/steps/01-apple-prototype-rebuild.md)。正式产品仍以 [PRD 1.0](../../../prd/README.md) 为基线。
