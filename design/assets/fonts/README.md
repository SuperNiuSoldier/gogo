# Go狗预览圆体

字体来源：[寒蝉全圆体 / ChillRound](https://github.com/Warren2060/ChillRound)，使用仓库中的 `ChillRoundF v3.0.ttf`。

- `godog-round-preview.woff2`：针对当前界面文字生成的 482 字符子集，包含 ASCII、中文界面文字及标点。
- 字体内部家族与 PostScript 名称已更改为 `GoDog Round Preview` / `GoDogRoundPreview-Regular`，保留原版权与许可信息；未重新绘制字形。
- [ChillRound-LICENSE.txt](ChillRound-LICENSE.txt)：随字体保留的原始 SIL Open Font License 1.1。
- [provenance.json](provenance.json)：来源、源字体 SHA-256 和子集说明。

当前预览内嵌该子集，不依赖访问者安装中文圆体，也不需要在运行时下载字体。使用常规字重并关闭合成粗体；未包含的用户输入字符回退到系统中文字体。正式应用的完整字库、其他字重和系统字号适配在 iOS 实施阶段处理。
