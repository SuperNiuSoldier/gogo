# 照片陪伴首页 v0.9

日期：2026-10-10。状态：根据用户“大面积照片、动态流转、功能折叠并点击弹窗”的要求更新，待评审。以下取代 v0.5–v0.8 首页布局；圆体、双狗身份、完整功能范围与记录准确性继续保留。

## 首页只呈现陪伴

1. 顶部：Go狗、外观入口，肉球 / 格林头像切换。
2. 主体：大幅当前狗狗照片，简短名字与问候；照片占主要面积。照片右上角提供管理入口。
3. 底部：「记一笔」「回忆」「更多」三个入口。点击才打开底部弹层，背景照片保留并变暗；收起后回到照片。

六宫格、健康卡、回忆摘要、照护流水、提醒列表均不常驻首页。照片区域不再兼任角色动画：照片流转是照片之间的切换；小狗自身的动作保留在「更多 → 和它玩一会儿」。

## 功能弹层

| 入口 | 展开内容 | 行为 |
|---|---|---|
| 记一笔 | 喂食、喝水、尿尿、便便、遛狗、日记；更多记录与今天的小脚印 | 前五项点一下记一次，日记打开编辑。保留补充、撤销；从首页计为两次点击 |
| 回忆 | 照片日记、第一次、狗狗与类型筛选 | 默认回忆，不摊开高频照护流水；复用已有记录模型 |
| 更多 | 健康、回忆、小提醒、我家、和它玩 | 二级内容在同一弹层切换，不叠套多个弹窗 |
| 照片 | 当前狗狗的展示照片 | 一次选择多张；可移除，不影响照片日记 |
| 外观 | 奶白 / 黑棕 | 只更换颜色，不改变照片集合、宠物 ID 或记录归属 |

弹层明确当前狗狗；背景不可交互，避免编辑过程中误换狗。返回回到来源；关闭按钮、背景遮罩或 Escape 可收起。未保存的日记、档案、提醒先确认，选择继续编辑则保留草稿。键盘焦点留在弹层内，关闭后回到原入口。长表单允许完整展开，原生阶段再验证系统半屏 sheet / 键盘避让。

## 照片流转

- 肉球与格林各自一组照片，绝不混播；切换狗狗立即清理旧转场并展示对应集合。每只保留当前照片位置。
- 多于一张时每 5 秒切换，约 650ms 柔和淡入淡出；不平移、旋转整张照片来冒充小狗动作。支持左右滑动、上一张 / 下一张与暂停 / 播放。
- 手动翻页或焦点进入翻页控件后暂停，主动按播放恢复；鼠标停留照片、打开弹层、页面隐藏或照片离开视口时暂停计时。
- 系统减少动态效果时关闭自动轮播和转场，仍可手动切换。不会朗读每一次自动切换；手动翻页播报位置。
- 一张照片静态展示；无照片时展示明确标注的「演示插画」，不把生成素材当成原照。用户原照添加后立即替换占位。
- 显示照片保持原比例，不套主题滤镜。展示照片不自动生成日记，也不改头像或照护数据。

## 原型输入与数据边界

当前服务器未找到用户此前四张 Windows 路径原照，默认仅用既有角色插画占位。添加入口接受 JPG、PNG、WebP，每只最多 12 张、每张最多 5MB、解码后最多 2400 万像素；HEIC 与系统照片权限留待原生阶段。

照片读入完成才加入列表；坏文件不会清空原照片。读取过程中收起弹层会取消本次尚未完成的导入，旧异步回调不得把照片写给另一只狗。照片及记录只留在本次预览内存，不写入宿主状态或提交到仓库。宿主只保存主题、选中宠物 ID、两种动画的暂停偏好。

## 点击角色动作

「更多 → 和它玩一会儿」保留 v0.8 的独立角色帧：肉球立耳奶白长毛、格林垂耳黑棕眉点；待机眨眼，点击歪头、抬爪，动作结束回到坐姿。暂停待机后仍可主动点击；减少动态效果时只回应文字。收起弹层、后台或不可见时取消动作。点击不生成任何照护记录。

素材仍为 AI 生成的有限二维动作帧，动作自然度待评审，详见[角色动作记录](../../../doc/steps/01-character-animation.md)。其余字段与规则见[每日记录](../../../prd/daily-quick-recording.md)、[回忆与提醒](../../../prd/detail-pages.md)。本轮实现、验证和限制见[照片首页实施](../../../doc/steps/01-photo-home.md)；原生 iOS、相册权限、持久化、通知和真机能耗尚未实现或验证。
