## 页面与信息层级

| 页面 | 首要内容 | 主要操作 |
|---|---|---|
| 今天 | 当前狗狗大幅照片、独立照片轮播与头像切换 | 管理照片；点击功能栏展开弹层 |
| 脚印弹层 | 六项快记、最近待办、小脚印历史入口 | 一键照护、写日记、更多记录、补充与撤销 |
| 成长 / 回忆 | 当前狗狗的回忆，唯一拍照按钮 | 拍照即留瞬间、查看、编辑、删除、补充 |
| 档案 | 当前狗狗名字及按需展开的资料 | 由更多直接编辑，不经过概览 |
| 更多功能 | 12 项等权重图标与名称 | 记录类和档案直接填写；提醒列表、陪玩分别进入 |
| 记录编辑 | 明确的狗狗、发生时间、必要字段与可选详情 | 保存、失败重试、放弃修改确认 |

## 主要路径

1. **一次快速照护**：打开今天 → 查看当前狗狗 → 脚印 → 点喂食 → 显示成功与次数更新。默认记录当前时间，食量可点“补充”填写。
2. **一次照片 / 文字日记**：脚印 → 点日记 → 选一张照片或写一句话 → 保存 → 回忆卡片。两者至少一项，v0.6 预览已支持单张照片。
3. **一次称重**：更多 → 体重 → 输入实际千克数 → 保存。没有体重数值不能生成称重记录。
4. **补记或纠错**：点记录 → 修改实际发生时间 / 内容 → 保存；在今天外的记录不计入今日次数。刚保存可撤销此次操作。
5. **查看健康**：脚印 → 记录历史 → 选择记录。顶部切换狗狗；更多中的健康项目直接用于创建，体重表单下方展示已保存记录的变化；健康附件另行设计。
6. **找照片回忆**：顶部选狗狗 → 回忆 → 查看它的照片与故事；无页内宠物选择，完整照护流水从小脚印进入。

## 字段与数据规则

- 档案名字必填；照片、生日、估计年龄、到家日期可跳过。未知生日不伪造，估计年龄标“约”。
- 陪伴天数按本地日历日差加一计算；到家当天为第 1 天，未知到家日期则不显示。生日、到家日期不接受未来值。
- 各记录至少有稳定 ID、狗狗 ID、类型、发生时间、创建时间；可选详情为空时明确视为未知。
- 同一时间按创建时间稳定排序；未来待办放在提醒，不伪装成已发生记录。
- 日记至少有照片或非空文字；里程碑有标题和日期，照片备注选填。
- 快捷保存成功后才更新次数；失败保留原界面并可重试。不能用“零次”代替加载失败。
- 修改过的草稿离开需确认；删除需确认；撤销绑定具体记录 ID 和之前状态。
- 主题只影响外观，切换主题不改变档案、记录归属和草稿。

## 首次使用与异常状态

未建档时先创建狗狗，再展示快捷记录；建档后的零记录状态展示照片；六项入口在快记弹层展开，不要求先写故事。不主动索取通知或相册权限，用户选照片 / 设提醒时才触发。取消选图保留文字，拒绝通知不影响记录。没有回忆时不生成虚构成就。

## 验证目标

有档案时从首页展开脚印再记一次照护共两次点击；必要字段才需要输入。验证多次记录、误触防重、跨狗撤销、补记、主题切换、失败重试与重启恢复。已完成的浏览器检查见阶段记录，不能据此宣称原生 iOS 已通过。
