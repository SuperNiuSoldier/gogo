# 用户功能清单

日期：2026-10-10。状态：按用户最新要求调整功能优先级；v0.3 视觉风格已确认，照片手账首页 v0.12 待评审。以下是完整首版设计目标，不代表功能已在 iOS 中实现。

## 产品主线

给狗狗记录每天的照护与成长：常做的事点一下记好，需要细节时再展开。产品同时覆盖日常照护、健康、日记、回忆与数据管理，不再把日常照护排到成长日记闭环之后。
默认无需注册，本地优先。用户创建自家狗狗的档案；肉球和格林是两套主题角色，不限制用户的狗狗名字与照片。至少支持两份独立档案。

## 按使用频率安排功能

除用户已确认的六项快捷记录外，下列频率分层为设计假设，后续用实际使用情况验证；不会自动改变按钮位置。

| 层级 | 功能 | 主要入口与交互 |
|---|---|---|
| 每天多次 | 喂食、喝水、尿尿、便便、遛狗 | 今天 → 脚印弹层六宫格，点击记一次，弹层显示次数角标，时间与流水在“小脚印”查看；可撤销、补充、补记 |
| 经常 | 日记 | 六宫格固定一席，打开编辑；照片或文字至少一项，允许过去日期 |
| 按需 | 称重、训练、洗澡、美容、自定义记录 | 更多 → 对应项目，直接进入简短表单；体重必须填数值 |
| 按需 / 周期性 | 用药、疫苗、驱虫、就诊与附件 | 更多 → 对应健康项目创建；脚印 → 记录历史回看，填写实际项目或用量 |
| 定时待办 | 喂食、遛狗、用药、疫苗、驱虫等提醒 | 快记弹层展示最近待办；更多 → 提醒管理，由主人设定时间与重复规则 |
| 随时回看 | 全部记录、照片日记、成长里程碑 | 顶部统一选狗狗；回忆与完整脚印分入口，支持编辑、删除、补记 |
| 周期回看 | 体重趋势、月度回忆、照片对比、分享图片 | 体重填写页已展示已保存数据的变化；月度回忆、照片对比与分享仍待实现 |
| 低频管理 | 建档 / 编辑档案、主题、快捷项配置、导出 / 备份 / 恢复 | 更多 → 档案直接编辑；主题在顶部，其他管理能力待实现 |

## 页面职责

当前底部为「脚印 / 回忆 / 更多」，点击展开弹层，页面布局以 [照片手账首页 v0.12](companion-home.md) 为准；下文为功能职责名。

- **今天 / 陪伴**：当前狗狗大幅照片与轮播，轻量头像和功能栏。
- **脚印弹层**：喂食、喝水、尿尿、便便、遛狗、日记固定顺序；附今日历史、更多记录与最近待办。
- **成长 / 回忆**：只保留「照相 · 留个瞬间」主按钮与当前狗狗的回忆，移除宠物 / 类型筛选；完整记录从快记的小脚印进入，里程碑创建位于「更多 → 第一次」。
- **更多功能**：12 项同级图标入口，记录类与档案直接填写；提醒与陪玩独立进入，不重复展示回忆。
- **档案**：只编辑当前狗狗资料，选填项折叠；换档案对象只用顶部头像。
- **记录编辑**：各入口复用同一套记录归属、时间、保存、失败保留与取消规则。

## 交互约束

1. 快捷照护只写入狗狗、类型、发生时间，不默认食量、水量、时长或排便状态。
2. 遛狗快捷按钮表示已经完成一次遛狗。计时功能后续单独设计，不把按钮同时用作开始与结束。
3. 日记、体重、用药等需要输入的内容不直接生成空记录；用药不提供自动推荐剂量。
4. 主题和记录对象独立；只有顶部切换当前狗狗，各页面同步刷新。记录、草稿、撤销都绑定明确的狗狗 ID，未保存内容切换前确认。
5. 日常记录支持当天多次、补记、编辑、删除；次数按发生时间所属本地日期统计，未来事件进入提醒。
6. 功能深度通过表单展开与固定入口承载；不要求每次重复选择狗狗和类型。
7. 正式版快捷项允许主动配置，默认固定六项；不根据推测的使用频率自动重排。

全局选择与拍照规则见 [顶部统一切换](global-pet-context.md)。具体字段、异常与验收见 [每日快捷记录](daily-quick-recording.md)。

## 实施批次与设计目标的区别

先实现基础工程，再打通档案 → 每日快记 / 日记 → 回看 / 编辑 / 撤销；接着补齐健康、提醒、体重趋势、回忆、导出与恢复。分批实施是工程顺序，不能将“功能较齐全”解释为只交付日记。
家庭共记、云同步、GPS 轨迹、社区、消费统计、徽章和复杂年度册仍为后续候选。

- 已有预览：双主题、双狗选择、五项一键照护、单张照片 / 文字日记、更多类型表单、补记、编辑、撤销与删除确认；v0.6 补充档案编辑、一次 / 每日 / 每周提醒与完成记录闭环。数据仅存在本次预览内存，详见[二级页设计](detail-pages.md)。
- 仍需设计 / 实现：多图和健康附件、正式健康结构化字段、系统通知及跳过 / 延期、完整趋势分析与回忆生成、建档 / 删除档案、快捷项配置、持久化、可恢复备份及导入。
- 待定：最低 iOS 版本、多图上限、多狗上限、导出与恢复格式；这些细节不阻塞快记交互设计。
