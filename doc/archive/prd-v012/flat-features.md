# 扁平功能与简短表单 v0.11

日期：2026-10-10。2026-10-12 补充：操作层级继续有效，当前视觉表现与体重回看见[照片手账 v0.12](paper-photo-design.md)。根据用户「功能冗杂、不扁平、一眼看不出功能、内部细化过多」的反馈，保留照片首页，将展开后的功能入口和填写步骤简化。本文件取代此前健康角、我家和更多记录的多层导航。

## 更多：一屏功能目录

点击底部「更多」展示 3 列 × 4 行等权重图标与名称，不再混用分类大卡、列表、回忆摘要和嵌套目录：

| 第一列 | 第二列 | 第三列 |
|---|---|---|
| 体重 | 疫苗 | 驱虫 |
| 用药 | 就诊 | 洗护 |
| 训练 | 第一次 | 自定义 |
| 提醒 | 档案 | 陪玩 |

- 记录类点开直接填写；「洗护」合并洗澡 / 美容的入口，表单中默认洗澡，可切美容，历史类型仍保留。
- 「档案」直接编辑当前狗狗，不再先经过名片概览；「提醒」进入待办列表；「陪玩」进入角色互动。
- 回忆只在底部「回忆」进入；照片只在首页照片角标进入；主题只在顶部外观按钮切换。不在「更多」重复放同一功能或内容摘要。
- 「脚印」中的「更多」打开同一个目录，返回回到脚印；其他操作完成回到来源目录。页面只保留一个标题、一组返回 / 关闭控件。
- 所有记录包括健康、洗护和训练统一在「脚印 → 记录历史」回看、修改、撤销和删除。本轮移除健康概览中间页，未删除既有记录；体重填写页已补充基于实际记录的变化，健康附件仍为后续能力。

## 内部：先完成一件事

| 功能 | 默认可见 | 按需展开 |
|---|---|---|
| 体重 | 千克数、保存 | 备注、记录时间 |
| 疫苗 / 驱虫 / 用药 / 就诊 | 一项实际内容、保存 | 记录时间 |
| 洗护 | 洗澡 / 美容、保存 | 备注、记录时间 |
| 训练 | 备注（选填）、保存 | 记录时间 |
| 第一次 / 自定义 | 内容、保存；第一次可附照片 | 记录时间 |
| 档案 | 名字、保存 | 生日、到家日期、小特点 |
| 新提醒 | 事项、提醒时间、保存 | 分类、一次 / 每天 / 每周 |

记录默认当前时间，选填项折叠在「补充信息」；不是删掉补记能力。编辑已有记录时展开详情，以便看见旧值。错误出现在折叠项时，自动展开并定位字段。体重仍须为正数，用药仍需药名与实际用量，不用默认值代替真实记录。

新提醒默认「其他、只这一次」，不要求先分类；完成一般事项直接以标题记下并可撤销。用户主动选为用药 / 疫苗 / 驱虫 / 就诊时，完成仍先填写实际内容；提醒保存不等于已经执行。

## 保留规则与边界

- 顶部唯一宠物切换、双主题恢复、草稿放弃确认、旧照片回调保护、具体记录 ID 撤销继续有效。无重复宠物选择。
- 照片首页、六项快记、拍照即留瞬间与独立角色动作继续保留。
- 当前仍是内存浏览器原型；原生相机、照片权限、通知、持久化、VoiceOver 和 Dynamic Type 不在本轮验证范围内。
- 实施与实际验证见[本轮记录](../../steps/01-flat-features.md)。
