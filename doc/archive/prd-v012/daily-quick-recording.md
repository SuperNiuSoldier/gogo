# 每日快捷记录 v0.1

日期：2026-10-10。状态：六项快捷入口由用户确认；记录规则持续有效，当前 v0.12 照片手账首页与弹层布局待评审。视觉沿用已确认的双主题 v0.3。

## 已确认输入与设计原则

用户希望交互简单，同时功能比较齐全；每天会频繁记录。确认默认六项快捷记录：喂食、喝水、尿尿、便便、遛狗、日记。

按使用频率安排入口，不把完整功能摊平在首页。六项位置固定，可在后续设置中主动调整；不自动重排。频率分层来自本次需求判断，不是已有用户行为统计。

## 首页结构

当前布局见 [照片陪伴首页 v0.12](companion-home.md)：首页以照片为主，点击底部「脚印」展开六项快记；小脚印、最近待办与补充 / 撤销留在弹层内。底部另外提供「回忆」「更多」弹层入口，主题选择仍在右上角。

- 每项保留文字和图标，有记录时显示当天次数角标；最近时间与明细放在历史里，无障碍名称也可读取。零记录不显示数字角标，不用“尚未喂食”等未发生断言。
- 主视觉展示当前狗狗，头像切换同时更新名字、形象和记录对象；主题控制配色，深色主题也可为肉球记录。
- 日记显示篇数，其余显示次数。数值依赖记录本身，未填的水量不能汇总成饮水量。
- 首页不展示近期回忆卡；弹层中的“小脚印”进入全部记录历史。回忆和全部脚印用不同入口区分；都跟随顶部当前狗狗，不再在页面内筛选宠物。
- 快记弹层中的最近提醒最多突出一项，其余进入提醒管理；当前预览不模拟通知。

## 默认操作与必要输入

| 类型 | 默认操作 | 可选详情 / 特别规则 |
|---|---|---|
| 喂食 | 点一下记一次 | 食物、克数、备注；没有输入时不推断数量 |
| 喝水 | 点一下记一次 | 毫升、备注；只观察到喝水也能记录 |
| 尿尿 | 点一下记一次 | 状态、位置、备注；不默认“正常” |
| 便便 | 点一下记一次 | 状态、照片、备注；不默认“正常” |
| 遛狗 | 点一下记一次已完成事件 | 时长、备注；计时与 GPS 另行设计 |
| 日记 | 打开编辑，填写后保存 | 照片或文字至少一项；v0.6 原型支持单张照片 |
| 称重 | 打开数字输入 | 实际正数体重必填，单位明确；不把上次体重作为新测量保存 |
| 洗澡 / 美容 / 训练 | 更多 → 对应项目直接填写 | 当前时间，项目和备注选填 |
| 用药 | 更多 → 对应项目直接填写 | 实际药名与用量必填；正式版结构化字段，不推算剂量 |
| 疫苗 / 驱虫 / 就诊 | 更多 → 对应项目直接填写 | 项目名称或就诊内容必填；照片 / 附件与下次提醒另填 |
| 里程碑 / 自定义 | 更多 → 第一次 / 自定义，填写内容 | 发生时间必填，照片可选 |

当前补充表单采用按需展开的可选详情；预览覆盖备注、时间，喂食 / 喝水 / 遛狗 / 体重的数值，以及日记 / 里程碑的单张照片。健康附件、结构化排便状态等仍待实现，不能将预览字段等同于完整范围。

## 保存、撤销与纠错

1. 一键照护带入当前狗狗 ID、类型、当前时间，保存成功反馈“狗狗 · 类型 · 时间”；更新该狗狗今日次数及历史。
2. 反馈提供“补充”和“撤销”。撤销使用具体记录 ID；换狗或换主题以后仍撤销原记录。
3. 修改的撤销恢复修改前版本，不误删整条记录；新建的撤销删除本次新记录。只保留最近一次可撤销操作；旧记录仍可在详情中编辑 / 删除。
4. 预览防误触间隔暂定同狗同类型 650ms；间隔内的连续点击不重复写入，不阻止其他类型 / 其他狗狗，也不合并真实的后续重复事件。正式版以异步保存状态与稳定操作 ID 防重复，650ms 阈值需真机评估。
5. 错过撤销仍可从历史纠错；删除明确确认。保存失败不能展示成功，需保留内容并给出重试，重复重试不得产生重复条目。
6. 保存中的反馈、持久化失败、崩溃恢复均为原生阶段验证项；浏览器临时数组不能证明这些能力。

## 时间与归属

- 所有表单打开时固定本次狗狗 ID。换主题、宿主外观状态更新不重新绑定草稿。
- 当天次数按发生时间与设备本地日期计算；补记昨天不增加今天次数，跨午夜恢复前台后重新统计。
- 未来时间不作为已发生记录保存；计划事项由提醒管理。创建时间与发生时间分开。
- 正式数据保留发生时区 / 偏移信息；跨时区历史分组方案在基础模型阶段细化，不能用固定 24 小时窗口代替本地日历日。
- 所有默认值和历史记录以当前狗狗为范围；不把肉球的食量或用药信息带到格林。

## 完整功能入口

当前脚印承担频繁记录与全部历史；回忆展示照片、日记和里程碑；更多以 12 项同级入口提供其他记录、提醒、档案和陪玩。体重填写页展示实际记录趋势；月度回忆、分享与数据管理为后续能力。完整清单见 [用户功能](user-features.md)。

提醒完成应显式关联或生成一条记录，防止“已提醒”被当成“已喂食”。v0.6 已设计并预览一次 / 每日 / 每周重复与完成流程，详见[提醒设计](detail-pages.md)；跳过、延期和系统通知仍待补齐。

## 验收清单

- 六个入口固定，普通照护从今天页只需一次点击；日记不会点击即创建空内容。
- 快捷次数、最近时间、历史三处一致；每只狗独立统计。
- 五项照护可多次记录，快速误触不重复；其他类型不受误触保护牵连。
- 换主题和换狗不改变已保存记录与撤销目标；草稿归属固定。
- 正数体重、日记内容、健康项目验证明确，失败保留用户输入。
- 补记后排序与日统计正确，编辑不额外增加条目，删除需确认。
- 320px 小屏、浅深主题、点击区和减少动画有浏览器检查；VoiceOver、Dynamic Type、键盘遮挡、安全区和真实通知在 iOS 环境验证。
