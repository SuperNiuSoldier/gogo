# 肉球 / 格林双主题设计（当前布局 v0.12）

日期：2026-10-10。状态：保留 v0.3 已确认的中文圆体、紧凑布局和双狗识别；根据用户要求，当前布局更新为照片手账首页与折叠功能弹层 v0.12，待用户评审。原生 iOS 尚未实现。

当前布局以[照片手账视觉](paper-photo-design.md)和[照片陪伴首页](companion-home.md)为准：真实照片不随主题改变，角色动作移至「更多 → 陪玩」。

## 已确认的设计输入

用户有两只狗，白狗名为肉球，黑狗名为格林。UI 必须保留两只狗各自的特征，不能融合；通过浅色 / 深色切换展现不同风格。

四张参考照片中，第 1、4 张为肉球，第 2、3 张为格林。只参考犬只和少量配饰，不把照片周围的相册界面、草地、窗帘等颜色作为狗狗毛色。色值为目视提炼后根据可读性调整，不是逐像素取色。

## 两套独立识别语言

| 维度 | 肉球 · 奶白 | 格林 · 黑棕 |
|---|---|---|
| 首要识别 | 奶白长毛、直立三角耳、蓬松颈毛 | 炭黑毛色、两点棕眉、宽垂耳 |
| 面部细节 | 深色圆眼、深色鼻头带轻微粉棕、浅色脸颊 | 棕色眼周与脸颊、黑鼻、吐舌时的少量粉色 |
| 身体轮廓 | 蓬松饱满、白色厚脚掌 | 耳朵向两侧垂落，黑色胸背、棕色前爪 |
| 界面氛围 | 温暖、柔软、明亮，类似浅色相册 | 安静、亲近、温暖，类似深色相册 |
| 强调色依据 | 围巾中的低饱和青绿色，少量使用 | 眉点、脸颊、前爪的暖棕色，少量使用 |
| 图形使用 | 照片为空时显示独立肉球插画、后续可提炼立耳与颈毛轮廓 | 照片为空时显示独立格林插画、后续可提炼棕眉与垂耳轮廓 |

两套主题共享组件和信息层级，角色轮廓、毛色和装饰元素分别维护。肉球不加棕眉、格林不改立耳；不做一张脸左右拼色，不在切换时把一只狗变形成另一只。正式记录中的照片始终保持原样，不套主题滤镜。

## 语义颜色

颜色源文件：[theme-tokens.json](../../../design/theme-tokens.json)。

| 用途 | 肉球 | 格林 |
|---|---|---|
| 页面底色 | `#F7F4EE` 奶白 | `#17191B` 炭黑 |
| 卡片底色 | `#FFFDFA` 暖白 | `#24272A` 暖炭灰 |
| 次级底色 | `#ECE7DE` 亚麻灰 | `#303337` 深灰 |
| 正文 | `#282B29` 深墨绿灰 | `#F5EEE3` 暖白 |
| 次要文字 | `#626760` 灰绿 | `#BDB6AB` 浅暖灰 |
| 主操作 / 选中 | `#3F655B` 雾青绿 | `#D5AD78` 眉点暖棕 |
| 主按钮文字 | `#FFFFFF` | `#201B15` |

大面积使用中性色，毛色识别由角色形象承担，强调色用于主操作、选中项和少量标签。粉色鼻头、舌头留在插画中，不扩展为第三套主色。
装饰分隔线与交互边界采用不同 token；输入框和可选控件不能仅靠很浅的装饰线识别。

## 主题与档案分别切换

- 顶部外观按钮展开后选择「肉球 · 奶白」「格林 · 黑棕」，平时收起。两个选项都含名称和选中状态，不能只给黑白圆点。
- 主题影响页面配色与氛围；用户选择应被保存。v0.11 首页照片展示当前档案的狗狗，名字、形象、记录归属一致，避免主题角色占据档案身份。正式版可增加“跟随系统”，本次仅手动切换。
- 预览恢复主题时兼容完整偏好与只含主题的保存状态，识别内部 ID 和「肉球 / 格林」名称；缺失或无效字段不重置当前主题、宠物。仅恢复主题不改变正在编辑的草稿归属。
- 记录对象只使用顶部头像栏选择：「肉球」「格林」，其他页面自动跟随。换主题不更改记录所属狗狗、不清空草稿、不切换当前页。
- 进入编辑页时锁定此次记录的狗狗 ID，编辑过程中换主题也不重新绑定。
- 首版设计范围明确包含至少两份独立狗狗档案；档案照片、年龄、到家时间和日记分别维护。真实生日和到家日期未知，本次不使用相册日期代替，不虚构年龄或陪伴天数。

## 页面应用

1. **陪伴**：品牌 / 外观按钮 → 宠物头像切换 → 当前狗狗大幅照片轮播 →「脚印 / 回忆 / 更多」功能栏。详细布局见 [陪伴首页](companion-home.md)。
2. **回忆**：当前狗狗的照片与故事，以内容为主；只留拍照主按钮，全部记录从小脚印进入。每条仍标注所属狗狗，主题不改变照片或内容。
3. **档案**：更多中直接进入编辑，选填资料按需展开；切换档案对象只用顶部头像。
4. **新增记录**：展示“写给肉球 / 格林”，单一保存按钮；普通照护在快记弹层一键记，日记 / 体重等先填必要内容。单张照片日记已有预览；完整健康字段仍待补齐。
5. **更多功能**：12 项同级入口，健康项目直接填写；体重页展示实际已保存的变化和最近三笔，完整历史在脚印回看，不推断健康结论。

## 排版与交互

- 根据用户“字体太尖锐”的反馈，改用真实中文圆体，以常规字重和圆润笔端呈现；标题不再用重黑字。预览嵌入 [寒蝉全圆体派生子集](../../../design/assets/fonts/README.md)，正式 iOS 版本仍需适配系统字号。
- v0.12 封面标题 38px（小屏 33px），用户照片标题 19px、弹层标题 17px，分组 16–17px，日记正文 15px，辅助 11–13px，输入 16px；均为预览参考值，原生 Dynamic Type 未验证。关闭合成粗体。
- 页面边距 16px，主要卡片约 22–26px 圆角；减少逐按钮描边，以统一照护区域和图标底形组织入口。保留至少 44×44 CSS px 点击区和快记按钮间 8px 间隔。
- 照片以 4:5 展示区域占据主要面积，原照保持比例，不拉伸、不融合；六项快记在点击底栏后展开。无原照时标注演示插画。
- 图标采用统一图标库；原生版本优先 SF Symbols。耳朵、眉点用于品牌形象，不替代保存、返回等功能符号。
- 点击区至少 44 × 44pt；正文和次要文字与实际底色至少 4.5:1。浅深两套分别计算。
- 切换只对色彩做短过渡，不混合两只狗的图像；减少动态效果时直接切换。
