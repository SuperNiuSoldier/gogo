# 第一版产品范围（初步）

更新：2026-10-10，依据用户“交互简单、功能较齐全、每日高频记录”的要求。
定位：狗狗的日常照护与成长记录工具，适用于幼犬及成年犬家庭。
主流程：创建狗狗档案 → 当天多次快捷记录 → 跟随顶部当前狗狗回看、补充。
导航：今天 / 成长 / 档案；首页快记与更多记录共用记录模型。

## 完整首版设计目标

1. 档案：至少两份独立档案，名字、照片、生日或估计年龄、到家日期；未知信息可跳过。
2. 高频记录：喂食、喝水、尿尿、便便、遛狗、日记。用户已确认这六项首页快捷入口。
3. 照护扩展：称重、洗澡、美容、训练、自定义事件；一天可多次记录，允许补记与修改。
4. 健康与提醒：疫苗、驱虫、用药、就诊、体重趋势、主人设置的提醒及完成状态。
5. 成长：照片与文字日记、里程碑、跟随顶部当前狗狗分入口回看，编辑与删除。
6. 回忆与数据：月度回忆、照片对比、分享、记录导出、可恢复备份与导入。
7. 易用性：默认无需注册、本地优先、两套主题、用户主动配置快捷项；主题与记录归属独立。

日常照护是首批核心，不再排在照片日记闭环之后。健康、回忆与数据管理属于完整设计目标，按工程阶段逐步落地；实际首发边界仍需在完整原型评审时确认，不暗中缩减上述目标。

## 暂不纳入
