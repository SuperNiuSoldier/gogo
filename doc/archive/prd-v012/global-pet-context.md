# 顶部统一切换与拍照回忆 v0.10

日期：2026-10-10。用户要求回忆只保留拍照留瞬间，切换宠物只在顶部完成。本方案取代此前页面内的狗狗筛选、全部狗狗视图与回忆页「记个第一次」主入口。当前功能入口与表单以 [v0.11 扁平功能](flat-features.md) 为准。

## 唯一宠物上下文

- 顶部头像栏是唯一切换入口，所有功能页共用一个当前宠物 ID；切换一次，照片、快记次数、回忆、历史、健康、提醒、档案与互动角色同步更新。
- 打开的功能面板保持在当前功能，顶部仍可点。面板采用非模态交互：照片 / 底栏暂不可点，顶部与面板均可键盘访问，不把焦点锁在面板里。
- 回忆和历史删除狗狗选择器，不提供「全部狗狗」；档案只编辑当前狗狗。页面内的只读名字用于确认归属，不再要求选择一次宠物。
- 切换本身不修改任何历史记录或草稿的宠物 ID。主题只改配色；顶部换主题不离开正在编辑的表单。
- 当前头像再次点击不重置页面、不丢草稿，也不弹确认。

## 未保存内容与异步任务

正常页面一键切换，无额外确认。有未保存的日记 / 档案 / 提醒，或照片正在读入时，才提示「放弃并切换」：

1. 继续编辑：保持原宠物、原页面和输入内容。
2. 确认放弃：作废旧文件回调、清理草稿，再切换宠物。表单回到对应的记录来源 / 更多目录 / 提醒页；不把旧草稿变成新狗的草稿。

确认尚未处理时，已读完的拍照或相册图片也等待决定，不提前保存；选择继续则仍归属原狗狗，选择放弃则丢弃待保存结果。

换狗后反馈条只显示当前狗狗的操作；撤销仍绑定具体记录 ID。已有照片、记录和小提醒保留原归属。

## 回忆只留一个拍照入口

回忆面板呈现标题、一个「照相 · 留个瞬间」按钮与当前狗狗的回忆内容；移除重复标题、狗狗 / 类型筛选及「记个第一次」按钮。

点击按钮后请求拍照，得到有效照片就生成一条当前狗狗的照片回忆。无需先选宠物、填标题、时间或正文。默认采用照片返回时的当前时间；之后可点回忆或「补充」修正时间、添加文字，也可撤销。

取消拍摄不生成空记录；照片无法读取时保留已有回忆并允许重试。首次拍摄的狗狗 ID 在入口点击时确定；切换宠物或关闭面板后旧结果失效，不能写入新狗狗。

已有文字日记与里程碑仍可回看。低频里程碑创建保留在「更多 → 第一次」；本轮只移除它在回忆页的独立主按钮。首页展示相册与照片日记仍为独立集合，拍照不会自动更换首页轮播照片。

## 当前预览边界

预览使用用户主动触发的文件选择与 `capture="environment"` 相机提示，桌面环境以选文件验证流程。拍照返回的 JPG / PNG / WebP 才接收，单张最多 5MB、最多 2400 万像素；有效照片保存在本次内存记录中。

具体手机是否直接打开相机取决于系统与浏览器；未实际验证手机摄像头、拒绝权限、HEIC 或系统照片库永久保存。原生阶段再实现系统相机和本地存储，不能把当前浏览器验证称为 iOS 相机已完成。[相机提示的兼容说明](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture)
