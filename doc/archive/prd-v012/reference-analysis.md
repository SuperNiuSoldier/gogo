# 产品参考与取舍

初次调研日期：2026-10-09；截图补充检查：2026-10-10。依据公开商店介绍、版本历史和官方网站。首次调研未逐张检查截图，本轮已目视查看 TA 的名字六张商店展示图；仍未安装体验，不据此断言实际手势、性能或所有最新页面。Go狗 的 v0.5 方案待用户评审。

## 本轮截图观察

TA 的名字在展示图中把宠物照片和头像切换放在高层，功能用浅色卡片承接，成长经历按里程碑时间线表达。Go狗 据此调整为宠物主视觉、轻量快记、健康和回忆卡，详细流水收进二级入口；没有复制竞品的品牌配色或直接使用截图资产。逐图观察与证据边界见 [对照记录](../../steps/01-companion-home.md)，当前方案见 [陪伴首页](companion-home.md)。

## 参考来源

| 产品 | 已核实的公开能力 | Go狗借鉴方向 |
|---|---|---|
| [TA 的名字](https://apps.apple.com/cn/app/ta-%E7%9A%84%E5%90%8D%E5%AD%97/id6771750239) | 宠物档案、健康、足迹、里程碑、徽章、消费与年度回忆；版本历史加入体重和家庭同步 | 档案中的陪伴感、成长事件、可分享的回忆；卡片直达内容 |
| [DogLog](https://www.doglogapp.com/) | 自定义事件、照片记录、提醒、照护协作和健康趋势 | 快捷记录、最近照护状态与事件分类 |
| [Doggy Time](https://apps.apple.com/us/app/doggy-time-puppy-potty-log/id1514159866) | 日常照护、训练、体重、提醒、多人照护与导出 | 幼犬高频记录的简洁入口，明确记录时间 |

TA 的名字商店介绍声称本地免登录，而 2.x 历史描述 Apple ID、云端和家庭共享。2026-10-10 查看[开发者支持页](https://lynn-nikita.github.io/pawprintSupport/)后补充：开发者说明基础记录可不登录，开启 CloudKit 后同步到 iCloud，家庭分享需相应账号能力。本轮仍未实际验证登录、数据迁移或同步行为。

## Go狗的产品判断

2026-10-10 更新：依据用户“交互简单、功能齐全、每日频繁记录”的要求，主线调整为“记好每次照顾，也留下成长回忆”。六项首页快捷记录已确认；本次仅更新 Go狗取舍，不把旧调研当作对竞品当前版本的重新验证。

| 参考能力 | 初步取舍 | 原因 |
|---|---|---|
| 宠物档案、陪伴天数 | 首批设计 | 打开应用即可看到自家狗狗 |
| 照片日记、第一次里程碑 | 首批设计 | 直接构成成长记录闭环 |
| 数据卡片直达模块 | 借鉴入口逻辑 | 点击数字应能查看对应记录，内容不足时不铺满空统计 |
| 喂食、喝水、尿尿、便便、遛狗 | 首批核心，与日记一起设计 | 用户确认六项快记，常规照护一次点击，按需补充 |
| 体重、用药与健康提醒 | 完整首版设计目标，后续工程阶段实现 | 体重必须输入，提醒日期由主人确认，不直接照搬自动接种计算 |
| 月度回忆、分享卡 | 第二批设计 | 让已积累的内容产生回看价值 |
| 地图、消费、徽章、年度长报告 | 暂缓 | 先满足日常照护与成长回看，避免首页模块过多 |
| 云同步、家庭共享 | 后续评估 | 需要明确离线、失败与冲突体验 |
