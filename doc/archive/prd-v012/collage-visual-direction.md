# Go狗拼贴视觉方向研究

日期：2026-10-10。状态：此前根据用户指定的 `surreal-pop-collage` 阅读原版后的方向提案。2026-10-12 收到具体设计截图后，当前方案以[照片手账视觉](paper-photo-design.md)为准；本页保留研究与适配理由。

## 参考来源

项目与已安装技能目录未找到同名包，已在线完整阅读作者的 [SKILL.md](https://github.com/2998980-hue/surreal-pop-collage/blob/main/SKILL.md) 与 [README](https://github.com/2998980-hue/surreal-pop-collage)。本轮为研究使用，没有安装或执行远程代码。

该技能面向照片转超现实波普拼贴：主体保持清楚可辨，通过少量大色形建立环境，再以一个夸张尺度元素形成视觉焦点；装饰和颜色须从参考场景推导，不能随机堆素材。

## Go狗的应用判断

- 主视觉：以一只狗为唯一主角，保留可辨认的轮廓、表情和毛色。平涂背景、剪纸边缘与局部叠压形成海报感，文字与主体建立明确大小关系。
- 肉球：奶白蓬松毛、直立耳朵、围巾为形状和配色来源，拟探索奶油底、青绿平涂形与舒展构图。
- 格林：黑毛、暖棕眉点与前爪、垂耳为识别重点，拟探索炭黑底、暖棕与奶油色的明确块面。保持黑色主题可用与清晰对比。
- 若使用夸张物件，每个主视觉只用一个，且需能说明它与狗狗或照片的关联；真实相册照片保持原样，艺术封面另作明确标识。
- 功能布局沿用扁平目录的操作深度，视觉呈现重新设计：名称直接可读，主次依靠尺寸、排版和少量色块组织；保存、取消和表单不承担拼贴装饰。
- 表单仍默认只展示必要输入，补充信息按需展开；只有顶部切换宠物。

## 适配与原技能的区别

原技能将主体去色并要求明亮画面；本项目已有「肉球与格林各自的毛色辨识」「保留黑色主题」的明确要求，优先保留这两项。因此参考其构图和色形方法，不声称完整照搬黑白主体规则。

当前服务器中可用的是已标注的生成角色资产；此前 Windows 路径原始狗狗照片未在项目中找到。后续视觉稿如继续使用生成资产，需保持来源标识，不能称为原照抠图。
