# 回看、PDF 导出与备份恢复

状态：待开始。

## 实施流程

1. 完善相册按月回看、记录与媒体来源导航；自动故事和照片对比是后续增强，不替代本阶段数据闭环。
2. 实现当前狗日期范围与类别选择、真实 PDF 预览、分页及系统保存 / 分享。
3. 实现整库备份的版本、文件和引用校验，恢复预览、替换确认、暂存与失败回滚。
4. 验证图片缺失、长文、批量导出取消、空间不足、损坏备份和未知版本，不输出假成功。
5. 验证恢复后内容、媒体、提醒关联和通知重新安排，无重复调度。

## 验收标准

- PDF 可实际打开，日期、数字、照片、数量与导出快照一致；长文分页无裁切。
- 真实执行导出备份 → 替换测试库 → 恢复，比对全部关系；失败时旧库可用。
- PDF 与可恢复备份的入口、文件用途清楚区分。
