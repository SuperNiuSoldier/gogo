# 照片手账视觉 v0.12

日期：2026-10-12。阶段 01 进行中，待用户评审。

## 输入和设计决定

用户提供他人设计稿四张，展示日记与相册、体重、导出和提醒。相较此前仅讨论 skill，本次有可直接观察的构图参考：照片突出，纸卡错层，细线与克制的按钮。以这组图修正此前工具网格视觉。

- 四张原始参考保存在 `design/references/tupina`，说明来源与使用边界；没有拿其中的宠物和数据充当 Go狗内容。
- v0.11 交互原型、目录截图与报告归档，当前视觉方案维护在 [prd/paper-photo-design.md](../../prd/paper-photo-design.md)。
- 复用既有生成素材中的坐姿帧，使用 canvas 在界面中显示独立剪贴小狗；未重新生成或修改参考图，不声称是用户原照抠图。
- 重做封面、轻量底栏、功能清单、照片纸卡、相册和提醒样式，保持现有数据归属与简短表单。
- 体重填写页增加根据已保存数据绘制的图表和最近三笔记录；空记录、一笔与多笔分别处理，不新增虚构体重。
- UI UX Pro Max 的 organic-biophilic 条目可支持柔和形状与自然色系；颜色仍来自已确认双狗规范与新参考，未采用条目的默认森林绿。字体、输入和点击区继续按项目规范检查。
