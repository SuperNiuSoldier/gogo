# 微信账号、云存储与订阅消息

状态：AppID 已写入工程；平台联调与云服务待开始。前置工程见[本地闭环](02-wechat-foundation.md)。账号类型、权限和发布资格尚未核验；本阶段未创建云资源、上传数据或发送通知。

## 实施顺序

1. 使用已配置的 AppID 在 Windows 微信开发者工具核验账号权限，完成首次编译和真机预览；在微信后台配置实际使用的隐私接口与保护指引。正式发布前另行确认账号主体与发布资格。
2. 选定并开通云环境，落实费用预算。服务端识别用户身份，数据库与存储均限制为所属用户可访问，不能相信客户端自报的用户 ID。
3. 增加本地操作队列、稳定 ID、上传重试、文件与记录提交顺序、删除同步和冲突处理；用户能分清本地已保存 / 上传中 / 云端已保存 / 失败重试。
4. 将本地开发版数据迁移到云端，明确用户确认、幂等、断网续传、失败回滚和空间控制。导出 / 恢复须真实执行，不用展示页替代备份。
5. 按实际主体和类目确认可用订阅模板；用户主动订阅后才调度服务端发送，记录授权与发送结果。没有授权或发送失败时保留待办，不显示已通知，不承诺无限重复通知。
6. 两个独立测试用户验证隔离，再进行换设备恢复、断网、多视频、删除和通知联调。

## 验收要求

- 本地首次闭环先经微信真机验证，再将云端标为可靠主存储。
- 无跨用户读写；旧本地数据迁移不重复、不丢失；失败与成功状态准确。
- 上传资源、消息或发布操作在用户授权范围内执行；密钥只放受保护配置，不进入前端或版本库。
