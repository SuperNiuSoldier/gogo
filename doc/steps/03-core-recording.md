# 档案、脚印与共享相册

状态：待开始。

## 实施流程

1. 实现首次建档、顶部多宠、资料编辑与移除，未知日期保持未知。
2. 实现五项一键照护、六项快记固定位置、日记多图 / 文字、第一次及完整历史；补记、编辑、删除、撤销按同一记录 ID 工作。
3. 实现日记叠卡与全部记录视图，覆盖无图、长文、多图、多记录及大字号降级。
4. 实现拍照直接保存、系统选图、共享媒体和相册自动汇集，散落照片与单图浏览 / 流转；不是维护两个图库。
5. 实现媒体来源追溯、移出展示、删除与撤销的关联规则，保持草稿、异步回调和宠物归属正确。
6. 验证离线、跨日 / 时区、重复保存、重启恢复和逐项导入失败，记录真实设备结果。

## 验收标准

- 建档 → 快记 / 拍照 / 日记 → 相册回看 → 编辑 → 重启恢复完整走通。
- 日记图片只保存一次即可在相册看到；删记录、删图、撤销都不会误伤其他关联。
- 按 PRD 的点击预算、双主题、多宠、空状态与数据量验收，不以静态截图替代联动。
