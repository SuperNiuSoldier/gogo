# 肉球主题实施

日期：2026-10-13。阶段：W02 视觉扩展。照片质感 v2 已生成并接入；用户视觉认可与微信真机确认待进行。下方前半部分为被替代的 v1 过程，当前实现以末尾 v2 记录为准。

## 需求与调整

用户希望以已经离世的萨摩耶肉球为主题，超越原来的颜色切换：照片风格背景、不同表情 Logo、日常动作简笔画。用户随后明确不增加选择照片等额外功能，而是提供真实照片，由 imagegen 生成背景并内置。

初步设计中的背景选择入口与存储逻辑已在交付前移除；没有新增背景文件选择 API、背景媒体引用或背景上传流程。相册原有媒体导入不受影响。

## 实现流程

1. 查阅阶段计划与现有工程。项目中只有历史生成插画、演示图集，没有用户最早在 Windows 提供的肉球原照文件；没有把这些生成图片当作真实照片背景。
2. 在 `scripts/build_rouqiu_theme.py` 绘制项目原生 SVG：12 个角色图形 × 2 种明暗。保留可编辑源、构建脚本与来源清单，复制到小程序运行资产目录。
3. 以立耳、白毛领、黑鼻子、浅绿围巾建立角色一致性。针对小尺寸审视后加宽脸颊、缩小相对耳朵比例、明确口鼻和蓬松身体，避免泛用猫形图标。图标仍需收到原照后做身份比对。
4. 新增 `features/appearance.js` 统一解析角色图标和通用控制图标；快捷记录、脚印串线、底栏及主题入口共用。关闭、添加、播放等通用操作保留直观符号。
5. 加入独立 skin 偏好和主题面板，保留原 light / dark 设置；兼容缺少 skin 的旧 v1 快照，不重置数据。空页使用肉球矢量插画；预留背景呈现层，当前没有虚构实拍背景。
6. 更新浏览器渲染检查，使图标路径随主题重新计算、图片 MIME 按真实格式处理；新增肉球三页、快捷面板、主题面板及空态场景。预览中的相册内容沿用合成测试数据，未进入运行包。

## v2：按参考图改为 imagegen 照片质感

用户否定 v1 图标外观，提供奶白萨摩耶近景参考，明确要求图标使用 imagegen。此次已执行生成，不再以 SVG 绘画代替。

### 实现

1. 使用内置 `image_gen`，每一枚素材单独调用，全部依据同一张用户参考。生成 12 枚透明底角色素材（喂食、喝水、尿尿、便便、散步、日记、体重、小事、相册、提醒、Logo、休息）及 1 张不透明竖幅写真背景。
2. 保留参考中的蓬松奶白毛、立耳、圆眼睛、大鼻子及鼻梁色斑、绿黄拼色围巾和圆吊牌。生成姿势作为主题视觉，不记录为真实经历。
3. 原始 PNG 保存到 `design/assets/rouqiu-theme/generated-v2`。同目录 `prompts.json` 保存 13 条实际提示词，`generation.json` 保存工具、参考与输出关系；私有参考目录加入忽略规则，参考原图不进入运行包。
4. `scripts/package_rouqiu_images.js` 用浏览器编码器等比例缩小、转为 WebP，保留透明度，不重新描图、抠图或修改内容。普通图标 256 px、Logo / 休息 480 px、背景最长边 960 px；13 个运行素材共 429,602 字节。原始生成图保留原样。
5. `features/appearance.js` 统一切到照片素材。深浅模式共用自然白毛图，不反色；通用加号、关闭和播放等控件继续用清晰符号。旧 v1 图标不再进入运行包，原构建脚本只可生成设计归档，避免覆盖新素材。
6. 快捷入口取消独立色块底，适当放大角色；底栏、串线、空态、主题切换共用新图。背景直接内置，相册空态展示主肖像，有记录时只在背景边缘衬托内容。没有新增背景选图入口，也不改宠物数据、头像或记录归属。

### 验证

- 已检查 13 个生成结果；透明素材包含透明像素与近不透明主体，WebP 均可解码。部分生成 PNG 的主体 alpha 为 254，因此校验接受接近不透明值，未强制改写透明度。
- Node 31 项通过；WXML 270 个原始绑定 / 50 个方法 / 运行资源校验通过。主包源码 895,056 字节，低于当前工程的 2 MiB 限制。
- WCC / WCSC 本地旧版语法编译通过。浏览器 150 组布局检查通过；人工查看奶白 / 黑色快捷面板、固定背景相册与主题面板，素材无白色矩形底。
- 这些不是微信原生运行结论。当前 Windows 开发者工具与 iOS / Android 真机中的 WebP、字体、层叠和点击效果仍待确认。
- 本轮未发布小程序、未提交或推送仓库。生成和接入已完成，不把用户尚未确认的视觉效果标为已验收。
