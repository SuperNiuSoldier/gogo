# 照护、照片体重线与日历提醒

状态：待开始。

## 实施流程

1. 复用记录模型实现洗护、训练、自定义与健康必要字段，照片凭证默认不进入首页。
2. 实现独立体重页：照片成长线 / 趋势、测量详情和短新增面板；相册和历史共享原记录。
3. 实现周 / 月日历、提醒定义与每次实例，完成、关联已记录事件、跳过、延期、系列编辑与撤销。
4. 实现通知权限、调度失败、实例变更后的取消与重排；拒绝权限不影响 App 内待办。
5. 验证逾期、多次重复、跨时区 / 夏令时及重启恢复，不补造漏执行记录。

## 验收标准

- 体重空 / 单点 / 多点、缺照片、修正和删除后各视图一致。
- 通知不等于完成；提醒完成与记录为一致事务，关联已有记录不重复记。
- 日历与实际系统通知分别记录验证证据，未送达不报已通知。
