# 移除相册、体重扩为记事

2026-10-12，阶段 01。用户明确要求脚印保留、相册直接砍掉、成长串线承载各种小事。

已在 gogo-next 三套候选统一移除相册导航和独立相册页面，默认脚印。照片选择、查看和播放进入脚印，新选照片形成照片日记。体重页改为记事，将当前狗的日常记录与称重按时间组成同一条成长线；保留原记录 ID、附件和详情编辑能力，无照片使用类型图标。

新增面板包含既有六项快记、体重与其他小事。快记从记事发起后仍停在记事；节点引用共享数据，不额外复制记录。

当前要求见 [记事 PRD](../../prd/notebook.md)。本轮专项结果写入 `design/previews/gogo-next/notebook-checks.json`；此前四页 / 五入口报告只代表此前版本，不作为新导航的验收证据。浏览器验证不代表原生持久化、通知或真机验证。


后续命名调整：用户要求仅改名——原脚印为相册，原记事为脚印。导航、页面标题、菜单标题与无障碍名称已同步修改；内部路由、数据与交互保持原样。已重新构建预览；标题和底栏名称另行浏览器核对。

后续拍照调整：相册「记一笔」改为直接启动相机选择，底栏移除拍照并使用三等分布局。成功导入后显示新照片，关闭查看返回最新照片日记；取消不创建记录。脚印里的小事快记保留。[专项结果](../../design/previews/gogo-next/camera-cta-checks.json)记录三套方案的选择器、取消、单条照片日记及时间线检查；真实手机相机尚未验证。
