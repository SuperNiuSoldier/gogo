# Apple 设计与 prototype 工具重构

日期：2026-10-12。阶段 01。三套完整交互候选已完成，待用户选择设计方向；原生阶段未开始。

## 输入与范围

用户明确要求使用新安装技能中的 Apple 设计与原型工具，「完全重构我们现在的 demo」。本轮覆盖四个主页面、统一导航、双主题、记录和编辑面板，以及照片浏览；不是只修一个局部动效。

使用 [prototype](../../.agents/skills/prototype/SKILL.md)、[Apple Design](../../.agents/skills/apple-design/SKILL.md)和 [Design Engineering](../../.agents/skills/emil-design-eng/SKILL.md)。prototype 默认建议限定一个组件，但用户明确要求完整 demo，因此以整个产品体验为统一设计对象，三套候选都具备完整上下文。

保留用户已确认要求：五入口、默认相册、顶部唯一切狗、肉球 / 格林独立识别、主题不切换宠物、圆润中文、少量说明、日常快记，以及正面上下滑动和滑走后渐进模糊的日记交互。

## 实现与设计

| 方向 | 探索轴 | 实际表现 | 代价 |
|---|---|---|---|
| 影集 | 单张焦点、沉浸回看 | 大图横向滑动和缩略片；照片日记；当前体重和趋势；轻薄浮动导航 | 同屏照片少 |
| 手账 | 照片与时间的情感关系 | 拼贴照片、日期短句、左右照片成长线、轻线日程 | 精确查找的密度较低 |
| 日常 | 高频操作与浏览效率 | 双列照片网格、紧凑记录、趋势和称重明细、同级提醒事项 | 单个瞬间的故事感较弱 |

源码在 [gogo-next](../../design/prototypes/gogo-next/README.md)，新的评审入口为 [gogo-next.html](../../design/previews/gogo-next.html)。`variants` 分别组织候选构图，共享已验证的记录与编辑逻辑；页面层次、材料、排版、图片呈现、导航和任务面板重新设计。旧 `gogo-life` 保留为过程证据，未改写其源文件和预览。

- 原型选择器逐字沿用 [PICKER.md](../../.agents/skills/prototype/PICKER.md) 的样式，置于上方，避免覆盖底部导航。一次只渲染一套完整方案，切换即时完成；支持数字、左右键和 R，编辑输入内忽略快捷键。
- 独立浏览器按 URL 的 `v` 参数保留方向；聊天 srcdoc 无法改历史，使用宿主偏好保留方向。方案切换保留狗、主题、页面、保存内容和当前草稿。
- 页面切换即时反馈，按钮按下有响应；短任务面板进入 220ms、退出 150ms，采用明确曲线与 transform，不阻塞新任务替换旧表面。键盘操作和减少动态效果不播放位置动画。
- 日记使用原生滚动，位移连续跟手，模糊限定内容层并减至最大 4px。原件和详情保持清晰，主操作栏稳定。影集的照片轨道同样为原生横向滚动。
- 减少动态效果下关闭自动播放、使用单张清晰日记；减少透明度时导航变为实色；高对比偏好提供明确轮廓。
- 实例卸载时清理全局事件、滚动监听、定时器和照片播放；异步导图结果不会再写回已卸载实例。
- 照片沿用有来源记录的生成样例，圆体生成独立子集；没有把第三方设计里的狗作为项目资产。

## 验证与修正

[浏览器检查](../../design/previews/gogo-next/browser-checks.json) 14 组通过，覆盖三套四页双主题、全局切狗、快记撤销、日记保存与回看、渐进模糊、体重、提醒完成与日历、照片播放、输入内快捷键排除、草稿 / 数据连续性、文件选择和减少动态效果，无 JS 运行错误。脚本为 [check_next_preview.py](../../scripts/check_next_preview.py)。

[布局检查](../../design/previews/gogo-next/layout-checks.json) 72 组通过：三套方向 × 320 / 375 / 390px × 常规 / 125% 字号 × 四页面。主页面操作不横向外溢，按钮至少 44px，当前日记完整。原型工具自身的 28px 高选择器按用户指定技能原样保留，不混入产品控件检查。

人工查看全部方向页面截图，发现并修正：

1. 影集日记的横向照片裁到了狗脸，改为从图片上方取景，确保当前示例的面部可辨。
2. 日常称重的通用 span 样式把缩略图拉大，限定内容文字才占弹性空间，照片恢复 43px。

这两处修正后执行了[专项检查](../../design/previews/gogo-next/touch-and-polish-checks.json)：三套日记的 Chromium 原生触屏上滑、滑动不误开详情、停稳点击与返回位置通过；影集横向触屏滑图通过；日常缩略图宽度通过。重新检查修正页面、记录面板和日记编辑截图。截图与报告位于 `design/previews/gogo-next`。

[构建报告](../../design/previews/gogo-next/build.json)确认当前预览小于 1MB、字体无缺字、picker 样式与技能一致。

## 范围与下一步

这是浏览器产品原型，不是可安装 iOS App。记录和选入照片仅在内存中；通知、本地持久化、真实 PDF、备份、档案管理等原生业务未完成。Chromium 触屏模拟不替代 iPhone Safari / 原生惯性、VoiceOver、系统照片权限、软键盘、Dynamic Type 和真机性能验证。

三套方向已经可直接评审。[prototype 技能](../../.agents/skills/prototype/SKILL.md)规定「Integration happens only in Phase 6, only for the variant the user picked」。因此本轮交付完整候选与比较工具，最终方向由用户选择后统一为主版本；未擅自替用户定稿。当前设计候选维护在 [PRD](../../prd/prototype-directions.md)。
