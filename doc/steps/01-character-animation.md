# 点击角色动作 v0.8

日期：2026-10-10。阶段 01 继续进行，视觉与动作自然度待用户评审。

## 用户反馈与改正

用户明确指出 v0.7 是图片晃动，并不满足“动态的小狗，点击后会有动作”。此前的缩放、平移和旋转全部撤掉，改为实际包含眼睑、头部、前腿和尾巴不同姿势的二维角色帧。v0.7 原型、截图及检查结果存档于 `design/previews/archive/*v07*`。

## 实施过程

1. 使用内置 image_gen（imagegen skill），以现有双狗插画为参照，分别生成 4×3 透明动作图集；肉球和格林独立生成，不融合花色和耳型。完整提示词、修正内容见[素材生成记录](../../design/assets/characters/generation-prompts.md)。
2. 目视检查生成结果。肉球有真实的开眼 / 半闭眼 / 闭眼、歪头、抬爪和掌心朝前动作；格林初稿部分帧换了前爪，追加一次连续性修正。修正稿的第 6 帧仍抬错侧，最终播放序列排除该帧，不将异常姿势接入动画。
3. 保留原 PNG，另外等比例生成 1024×768 的 WebP 用于内嵌预览。只做尺寸和格式封装，不在脚本中重绘、擦除或合成角色。根据固定着地前爪的位置测量每帧绘制偏移，减少脚掌滑动；绘制时隔开后两行顶部 3px 的邻格边缘，避免上一格脚底残片进入画面。
4. 使用固定大小画布逐帧绘制。待机采用闭眼序列，点击播放抬爪序列。没有整图 CSS 动画、缩放或旋转；画布和点击区保持固定。素材和动作顺序见 `design/assets/characters/sprite-manifest.json`。
5. 点击优先于待机眨眼，重复点击不排队；切狗、离页、隐藏和减少动态效果取消计时与旧回调。暂停改为控制待机，主动点击仍可播放动作；系统减少动态效果启用时只给文字反馈。
6. 保留原有快记、日记、档案与提醒的归属和数据边界。宿主仅保存主题、选中宠物 ID 和待机暂停偏好。

UI UX Pro Max 的宽泛交互查询返回触觉 / AI 反馈，未采纳；缩小到 `reduced motion` 后命中系统偏好和限制动画数量，继续采用这两条原则。

## 遗留与边界

- 当前为有限动作的二维帧动画，不是可任意操控关节的三维 / 骨骼模型。AI 帧之间可能仍有毛发、轮廓差异，动作自然度需用户评审；后续若要更多动作，应继续采用同角色连续帧或制作正式角色骨骼资源。
- 原生 iOS、VoiceOver、Dynamic Type、低电量 / 后台能耗与真实设备帧率未验证。
- 原型业务数据仍是临时内存；本轮未提交或推送 GitHub。
