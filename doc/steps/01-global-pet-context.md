# 顶部统一切换与拍照回忆 v0.10

日期：2026-10-10。阶段 01 进行中，待用户评审。

## 输入与实施

用户根据回忆页和顶部头像栏截图，要求回忆只需「照相、留个瞬间」，切换小狗只在顶部一次完成，其他页面不再重复选择。

1. 将同一组顶部头像移到功能面板之外，保留唯一的全局宠物 ID。照片与底栏仍在展开面板时禁用，顶部可用，因此将面板明确为非模态对话区域，并移除不适用的面板焦点循环。键盘可从面板返回顶部切换。
2. 删除回忆中的狗狗 / 类型筛选和「记个第一次」按钮；合并重复标题。回忆只显示当前狗狗的日记 / 既有里程碑，完整记录从快记「小脚印」进入，同样只看当前狗狗。
3. 拍照入口主动触发文件捕获；图片成功解码后直接新增照片回忆，后续可补充或撤销。取消、坏文件不新增记录；固定拍摄时的宠物 ID，并用请求版本作废过期回调。若用户正在决定是否放弃并换狗，拍照与相册导入等待决定后再提交：继续编辑保存到原狗狗，放弃则作废结果。
4. 全局切换同步照片集合、快记、历史、健康、提醒、档案和角色。档案只显示当前狗狗；普通页面直接切换，有未保存内容才确认放弃。确认后先作废读取 / 草稿，再切换，不修改旧记录归属。
5. 外观选择回到顶部的展开区域，换颜色不会切走表单。旧狗狗的撤销反馈不会留在新狗狗页；回到原狗狗后仍可撤销对应记录。
6. UI UX Pro Max 查询 `redundant entry repeated selection` 命中复用已确认输入的建议，结合用户明确要求采用一个全局宠物上下文。查阅 [MDN capture](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/capture) 确认相机提示不等同于跨浏览器相机能力保证；没有使用模拟相机画面声称真机已通过。
7. v0.9 原型、首页截图、报告与设计快照保存至 `design/previews/archive/*v09*`；同步当前 `prd`，历史记录保留版本含义。
