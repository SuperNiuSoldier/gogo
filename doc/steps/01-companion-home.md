# TA 的名字参考与陪伴首页 v0.5

日期：2026-10-10。阶段 01 仍在进行，当前设计待用户评审。

## 参考证据

查看 [TA 的名字 App Store 中国区页面](https://apps.apple.com/cn/app/ta-%E7%9A%84%E5%90%8D%E5%AD%97/id6771750239) 的公开介绍、版本历史及六张商店展示图，也打开了[开发者支持页](https://lynn-nikita.github.io/pawprintSupport/)。本次通过浏览器加载并逐张目视查看商店图片；没有安装 App，不据此断言实际手势、响应速度和异常行为。商店图片也不必然代表当前所有页面的最新状态。

| 图序 | 实际可见内容 | 对 Go狗 的启发 |
|---|---|---|
| 1 | 大幅宠物照片、名字、下方功能卡片，照片比操作列表更突出 | 宠物身份成为首页主视觉 |
| 2 | 顶部多宠头像，照片区域，下方浅色功能卡与底部导航 | 档案切换放在上层，功能以生活场景组织 |
| 3 | 家庭页面中按成员、同步等职责分组 | 低频管理留在二级页，不挤占每日入口 |
| 4 | “我的”页同时呈现宠物头像与管理行 | 家庭 / 档案管理独立于日常记录 |
| 5 | 成长事件按时间线排列，重要节点采用不同大小的圆形标记 | 日记 / 第一次需要叙事层级，避免与所有照护流水平铺 |
| 6 | 成就按类别分组，已获得与未获得呈现不同状态 | 空状态和已发生内容应有清晰区分；不因此新增未经确认的徽章模块 |

介绍明确描述首页卡片直达功能；这来自公开文案，不是本次点击安装版 App 验证的结论。卡片、照片和时间线的布局来自截图观察。

图片的浏览器检查截图暂存在项目 `.tools/ta-store-screen-1.png` 至 `6.png`，只用于参考分析，没有把竞品图片嵌入 Go狗 预览。原图链接仍由上述 App Store 页面提供。

## 设计变更

- 用户认为 v0.4 像日记 / log 且过于正式；问题是信息组织，不只是字体或颜色。
- 首页改为头像切换、宠物主视觉、轻量快记、健康与回忆卡。详细次数 / 时间 / 流水收进“小脚印”，保留真实记录与纠错能力。
- 导航展示名改为“陪伴 / 回忆 / 我家”。回忆入口默认筛选日记与里程碑；首页历史入口仍能看到全部记录。
- 原来的主题主视觉改为当前宠物主视觉，名字 / 图像 / 记录对象一致。主题控制配色，不改变记录对象；白狗立耳长毛、黑狗垂耳棕眉的独立形象继续保留。
- 新增健康角，展示实际最近体重，支持称重和健康分类创建；返回路径保留上下文。
- 旧版本保留在 `design/previews/archive/*v04*`；产品方案见 [陪伴首页](../../prd/companion-home.md)。

## 技能使用与取舍

使用项目内 UI UX Pro Max。设计系统查询返回宠物相关的圆润、柔和、轻量交互方向；其中营销页面滚动叙事、通用橙蓝配色不适合当前产品，未采用。追加 `pet app --domain product` 命中 Pet Tech App，采纳亲近、柔和的表现方向，继续以用户已确认的狗狗色彩为准。
可视化插件在工作中由本地 1.0.47 更新到 1.0.49，重新定位并完整读取技能后使用新的 render.py 包装检查。
