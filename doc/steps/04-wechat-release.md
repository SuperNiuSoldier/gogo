# 微信小程序真机验收与发布

状态：待开始。

1. 以当前[小程序首发需求](../../prd/wechat-release.md)建立逐项验收记录，重点检查照片 / 视频、通知授权、数据保存与恢复、两宠隔离、双主题和手绘视觉。
2. 完成不同尺寸 iPhone / Android 微信真机测试，记录系统 / 微信 / 基础库版本。验证软键盘、返回、隐私拒绝、减少动效、字体放大、长数据和后台恢复。
3. 云资源费用、容量控制、异常处理、数据删除与支持渠道明确；PDF、备份等首发边界与实际交付一致。
4. 按微信后台当时有效要求完成主体、类目、备案、隐私声明及素材授权核对，上传体验版进行连续日常试用。
5. 核对简介、图标、截图、审核说明；在用户授权范围内提审与发布，记录审核反馈并修复。

未进行微信编译、真机、体验版、审核或上线验证。旧 iOS / TestFlight 计划保留为未来原生平台参考。
