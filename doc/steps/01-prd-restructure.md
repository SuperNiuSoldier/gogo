## 输入与确认

用户要求仔细对照他人设计稿，尽量贴合设计，重构 PRD，并指出现状过于像 demo。本轮逐张查看日记 / 相册、体重、提醒、导出四图，区分可见布局、截图功能声称与设计推断。

用户在本轮明确选择「采用参考式五入口」：脚印、相册、拍照、体重、提醒；默认相册，顶部统一切狗。其余字段、容量、流程与首版范围是本次需求提案，未冒充用户逐项确认。

## 关键修正

1. 用四个完整内容页与一个中央拍照动作取代三入口弹层。此前“折叠功能”保留为新建 / 编辑短面板，不再让内容浏览也挤在面板内。
2. 相册成为真实资料入口，日记照片、拍照与称重图共享媒体和来源；撤掉首页展示图库与日记照片的独立集合。
3. 日记叠卡按真实记录建立，体重先看照片成长线 / 趋势，提醒先看周历 / 月历和实例，避免把输入表单当作完整功能页。
4. PDF 与备份恢复进入完整首版设计目标，补齐本地事务、草稿、失败、关联删除、通知实例等长期使用规则。
5. 保留奶白 / 黑棕、双狗身份、六项快记和唯一切宠；页内不复制宠物选择器。原生模态表单退出后使用同一顶部切换，与旧非模态 Web 焦点实现区分。
6. 将旧原型版本与 PRD 版本分开；旧预览不是新设计交付，不更改旧浏览器通过报告为“新产品已验证”。
