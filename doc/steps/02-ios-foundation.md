# iOS 工程基础

状态：待开始。

## 实施流程

1. 在 macOS / Xcode 中建立工程，确认最低系统、Bundle ID、设备与实际系统能力；当前 PRD 不假定已完成这些验证。
2. 实现相册 / 脚印 / 提醒三入口、相册内拍照动作、顶部唯一宠物上下文、双主题；默认相册，来源页和浏览位置可恢复。
3. 按 PRD 1.0 定义宠物、记录、共享媒体、来源关联、提醒实例和草稿模型；选择本地存储方案与迁移策略。
4. 先验证记录和照片 / 视频原件的事务保存、幂等重试、失败恢复与重启读取 / 播放，再接入业务 UI。测试内容与正式空库分开。
5. 评估系统照片与视频选择、HEIC / 静态照片降级、MP4 / MOV 及 HEVC 解码、批量导入、封面生成和通知调度；记录实际设备结果。

## 验收标准

- 模拟器能浏览三页，相册内拍照为动作；取消回到来源页，没有重复切宠入口。
- 应用终止重开后，已保存记录、照片 / 视频及其关联完整，视频可播放；失败无假成功，草稿不会变成已发布记录。
- 部署版本、媒体格式预算和迁移 / 回滚策略明确，未验证能力继续标为待验证。
