# 回忆、档案与提醒原型 v0.6

日期：2026-10-10。阶段 01 进行中，当前原型待用户评审。

## 输入与实施

用户在陪伴首页改版后要求继续。沿用已确认的双狗特征、圆体和紧凑方向，进一步让二级功能能够实际操作；不把“功能齐全”理解为在首页堆叠更多流水。

1. 将 v0.5 原型、首页截图和检查结果留存到 `design/previews/archive/*v05*`。
2. 回忆页增加“留个瞬间 / 记个第一次”，以照片卡片呈现日记；没有真实照片的示例仅使用明确标注的角色插画。支持单图读取、替换、移除，校验大小 / 类型 / 可解码性，处理连续选图的异步覆盖问题。
3. “我家”名片可编辑名字、生日、到家日期和特点；使用稳定 ID 保留记录归属。宠物改名不修改肉球 / 格林主题身份。
4. 增加提醒列表、编辑、一次 / 每日 / 每周规则；从我家和健康角进入，首页只显示最近一项。完成普通照护会生成实际记录；健康类填写内容后才完成。撤销同时恢复提醒和记录，阻止同一次完成的重复点击。
5. 修正回忆筛选另一只狗后新增日记的归属；清理旧页底按钮的间距，使回忆页两项操作对齐。
6. 更新 [当前产品方案](../../prd/detail-pages.md)、功能清单、页面流程及字体子集；未将原型行为标为 iOS 业务完成。

使用项目内 UI UX Pro Max 的表单错误 / 提交反馈建议，错误在表单内保留并将焦点移到对应字段。继续使用已经确定的产品颜色，不套用新营销模板或混合两只狗的花色。

## 原型边界与下一步

- 照片、档案、提醒和记录在预览内存中，重载 / 关闭清空；没有系统通知或后台任务。宿主状态只保留主题及选中宠物标识，不包含用户输入或照片。
- 目前仅支持一张 JPG / PNG / WebP。系统相册、HEIC、多图、压缩与附件持久化尚未实现。
- 提醒尚无跳过 / 延期、实际记录关联、原生通知权限及后台调度；跨时区、夏令时规则待 iOS 阶段验证。
- 档案目前编辑现有两只狗，首次建档、增删档案、头像替换与数据恢复仍需补齐。
- 原生 VoiceOver、Dynamic Type、系统键盘遮挡、安全区与数据重启恢复未验证；阶段 02–06 未因此提前完成。

后续先完成首次使用及异常状态设计，再进入原生工程基础。本轮没有提交或推送仓库。
