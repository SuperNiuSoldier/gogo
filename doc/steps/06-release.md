# 原生验收与发布准备

状态：待开始。

## 实施流程

1. 依据 PRD 1.0 验收矩阵在模拟器和真机逐项验证，不继承旧浏览器脚本的通过状态。
2. 验证四页双主题、两宠、空 / 多数据、Dynamic Type、VoiceOver、键盘、安全区与减少动态效果。
3. 验证离线、长数据性能、真实相机 / 相册、通知、重启、迁移、PDF 与备份恢复；记录设备和结果。
4. 准备图标、截图、隐私说明和商店元数据；核对发布时有效要求，描述与实际能力一致。
5. 配置签名和 TestFlight，具备账号权限并在用户授权范围内执行上传 / 提审。

## 验收标准

- 验收矩阵有具体证据、失败项与处置；核心数据、权限或恢复问题未解决不标为产品完成。
- 发布资料与实际交付一致，真实用户数据和密钥不进入版本库。
