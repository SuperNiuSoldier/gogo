# 双狗主题设计记录

日期：2026-10-10。阶段 01 的子任务，阶段整体仍为进行中。

## 输入与决策

- 用户提供四张照片，明确两只狗的特点必须分开，黑白主题分别呈现。
- 名字由用户确认：肉球（白狗）、格林（黑狗）。
- 将初步草绿主色调整为肉球奶白 / 雾青和格林炭黑 / 暖棕两套主题。
- 主题切换与档案切换采用两个独立状态，防止界面外观改变时误记到另一只狗。
- 本轮明确首版设计至少支持两只狗，更新先前“多宠待确认”的条目。

## Skill 与生成过程

使用项目内 UI UX Pro Max 的设计系统查询与原生 UI 检查规则。
第一次 `pet journal warm minimal` 命中了学术期刊风格，判定不适用；一次改写为 `pet care mobile` 匹配宠物配色与柔和风格，但其网页叙事结构、橙蓝色和厚重 3D 效果未采纳。当前颜色取用户照片灵感。
SwiftUI 的 `appearance theme` 及一次 `dark mode` 重试均无匹配；未据此声称命中。深浅色指导使用本地 `references/pro-rules.md` 通用原生 UI 规则，当前未交付 SwiftUI API 实现。

内置 imagegen 使用四张照片作为参考，生成左右独立的角色图；插画与提示词见 [生成记录](../../design/assets/character-generation.md)。原输出立即复制到项目目录，后续引用均在本项目内。预览仅做同尺寸 JPEG 压缩和显示区域选择，不重绘源图。

## 验证结果

- 颜色计算：24 组正文、次要文字、按钮及控件边界组合全部达到对应阈值；正文最低 4.70:1。发现并加深了肉球主题在次级底色上的次要文字。
- 浏览器：Chromium 中检查 320×900、375×900、390×900、768×1024、844×390 两套主题，共 10 组布局；无页面横向溢出，首页可见按钮均至少 44×44 CSS px。
- 行为：主题切换、编辑中保留草稿和记录归属、空文本提示、保存到内存、取消与继续编辑、放弃草稿、三页导航和减少动态效果均通过。
- 修正预览环境禁止默认表单提交的问题，改为本地点击处理后重新通过上述检查。未执行网络提交。
- JavaScript 运行错误为 0；检查详情见 [浏览器记录](../../design/previews/browser-checks.json)。
- 已目视检查 [肉球首页](../../design/previews/rouqiu-home.png) 和 [格林首页](../../design/previews/gelin-home.png)。校验环境补充中文字体，并修正标题继承预览宿主字体的问题。
- Markdown 本地链接检查通过，内嵌预览约 194 KB，满足 1 MB 限制。
- 浏览器与依赖仅保存在项目 `.tools` 中，并加入忽略规则；这些检查不代表原生 iOS 验收通过。

## v0.3 反馈修订：字体与留白

- 使用 UI UX Pro Max 的 `rounded friendly mobile` 字体检索与 `content density spacing` 排版检索；其推荐字体主要覆盖拉丁字符，因此另选并核实支持当前中文字符的 [寒蝉全圆体](https://github.com/Warren2060/ChillRound)。
- 圆体子集重命名并保留原始许可，嵌入约 245 KB 的预览中，取消依赖本机圆体字体。字体来源详见 [记录](../../design/assets/fonts/README.md)。
- 横向狗狗卡片取代独立大标题与全宽插画；减少区块间距，保留可点击区域。原始角色图未修改。
- 390px 宽首页由 1057px 高变为 620px 高；v0.2 源文件、截图和检查记录已归档。
- 新版本复查 10 组主题 / 尺寸布局、44px 点击区、字体加载、草稿及记录归属、空输入、保存 / 取消、导航和减少动态效果，全部通过。源色值未改变，沿用原有对比度结果。
- 两套最新截图已目视检查；原生 iOS 与系统大字体验证仍未完成。
