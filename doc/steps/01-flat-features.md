# 扁平功能与简短表单 v0.11

日期：2026-10-10。阶段 01 进行中；功能检查通过，用户已进一步指出视觉不足，未确认该版视觉。新参考研究见 [surreal-pop-collage](01-collage-skill-review.md)。

## 输入与实现

用户指出「更多」分类卡片与嵌套功能冗杂，无法一眼看到具体能力，内部细分也太多。

1. 将分类卡片、设置列表和回忆摘要合并成 12 项同级功能网格。记录功能直接进入编辑；档案直接编辑。去掉健康角、名片概览与二次记录类型目录。
2. 洗澡 / 美容共用「洗护」入口，保留原记录类型。历史记录统一由脚印进入，不迁移或删除既有数据。
3. 记录时间及可选备注收进「补充信息」，保留必填校验；既有记录编辑展开详情。档案默认只显示名字，新提醒默认只显示事项与时间，分类和重复按需展开。
4. 合并重复标题与返回按钮，复用一个功能面板；从脚印打开更多可以返回脚印。未保存内容保留 / 放弃、校验定位、顶部换狗和主题恢复继续有效。
5. 一般提醒默认其他类型，完成直接使用事项标题记下并可撤销；健康提醒仍要求实际内容。
6. 使用 UI UX Pro Max 的明确标签、按需展开和点击区规则。两次定向搜索未得到贴合「扁平导航」的条目，本轮取舍依据用户明确要求与技能基础规则，不把无关搜索结果视为设计依据。
7. v0.10 预览、验证报告与首页方案快照归档至 `design/previews/archive/*v010*`，当前方案维护在 [prd/flat-features.md](../../prd/flat-features.md)。
