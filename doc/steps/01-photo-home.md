# 大幅照片与折叠功能 v0.9

日期：2026-10-10。阶段 01 进行中，待用户评审；未进入原生 iOS 实施阶段。

## 输入与调整

用户认为页面功能展示过多，希望平时大面积展示小狗照片、动态流转，功能折叠并点击弹窗。本轮将布局从常驻六项快记 / 健康与回忆卡改为照片主体，底部仅「记一笔 / 回忆 / 更多」三个入口。

既有 v0.8 点击角色动画移至「更多 → 和它玩一会儿」。照片淡入淡出不承担角色动作，两种交互分开；两只狗的身份、花色和照片集合独立。v0.8 预览、报告和首页截图已存入 `design/previews/archive/*v08*`。

## 实施过程

1. 检查项目与当前附件目录，没有找到用户此前四张 Windows 路径原照；现有可用角色图是 AI 插画。因此标明「演示插画」，新增按狗狗选择多张本地照片的入口，不生成照片冒充原照。
2. 保留原配色与圆体，首页以 4:5 大幅照片区域为主。照片保持比例，自动切换为 5 秒停留 / 650ms 淡入淡出；手动翻页、暂停、减少动态效果、后台与不可见暂停共同控制一个计时器。
3. 将快记、回忆、健康、档案、提醒和表单放入同一个底部弹层。背景设为 inert，焦点限制在弹层，收起时返回原入口；关闭 / 遮罩 / Escape 复用草稿确认，保留原记录校验、撤销与狗狗归属。
4. 展示照片与日记照片分开，集合以稳定宠物 ID 管理。坏文件保留旧照片，关闭导入作废旧请求；图片只保存在内存，宿主状态只包含外观和暂停偏好。
5. UI UX Pro Max 查询 `modal focus return` 命中焦点可见性，`carousel auto rotating pause` 命中轮播暂停、按钮替代手势、焦点 / 悬停 / 减少动态效果停止。按当前组件实际范围采用。
6. 实测发现焦点变化时重新创建全部图标会吞掉第一次翻页点击，改为切换预先存在的播放 / 暂停图标，保留其他按钮 DOM。补充真实鼠标点击验证。
7. 同步 `prd` 当前页面职责与流程；保留历史实现文档的版本含义，旧测试脚本标明适用版本。

## 验证结果

- [浏览器报告](../../design/previews/photo-home-browser-checks.json)：12 组行为检查通过，覆盖首页收起状态、弹层焦点 / Escape / 遮罩、五项快记、跨狗撤销、日记草稿、体重校验、提醒完成与撤销、档案改名，以及移入弹层的角色动作。
- 多图导入、5 秒自动切换、手动翻页首次点击、显式播放 / 暂停、弹层暂停、鼠标停留、模拟后台、实际滚出视口、实时减少动态效果、宠物集合独立、坏文件保留原照片、删除至一张 / 零张，以及延迟导入取消均通过。使用既有生成素材作为测试文件，未将其当作原照验证构图。
- 23 组布局检查通过：320、375、390、768px 与 844×390 横屏首页，两套主题的小屏快记弹层及编辑表单；无水平溢出，可见按钮至少 44×44 CSS px。没有捕获 JavaScript 运行错误。
- 目视检查两套首页与展开的快记弹层。照片上的文字使用随标题高度延展的渐变遮罩，避免长名字脱离可读区域；[叠加颜色计算](../../design/previews/photo-overlay-contrast.json)在纯白底图这一最亮情形下，标题 / 辅助文字的最低遮罩对比度为 8.93:1，照片入口与标签为 7.53:1。
- JavaScript 语法、唯一元素 ID、本地文档链接和片段尺寸检查通过。当前约 917KB，中文圆体覆盖 483 字符；图片与字体内嵌，无运行时图像请求。
- 可复现脚本：[check_photo_home.py](../../scripts/check_photo_home.py)。v0.6–v0.8 的旧报告与脚本保留版本标识，不当作本次全量回归结果。

## 边界与遗留

- 默认仍是插画占位；用户添加至少两张原照后才实际轮播。原照构图与真实使用效果需用户补充照片后评审。
- 浏览器选择器支持 JPG / PNG / WebP，每狗最多 12 张、单张最多 5MB、最多 2400 万像素。尚无 HEIC、照片权限、永久保存、相册同步或通知。
- 原生 sheet、键盘避让、VoiceOver、Dynamic Type、真实触摸手势和真机能耗尚未验证。
- 功能与照片都在本次预览内存；关闭后清空。未提交或推送 GitHub。
