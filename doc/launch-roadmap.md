## 第一个可验收版本

先交付可安装到 iPhone 的最小闭环：首次建档 → 拍照或导入照片 / 视频 → 保存一条记录 → 强制退出 → 重开仍能查看 / 播放 → 编辑 / 删除。随后补齐其余功能与发布质量。现有视觉方向延续到原生，必要适配通过真机比较验收。

需要可用的 Mac / macOS 构建环境与测试 iPhone；正式分发前需 Apple Developer Program 账号与相应权限。账号、证书与用户数据不进入仓库。本轮仅记录路线，未配置账号、创建工程或上传。
